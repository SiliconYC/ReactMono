# Pygame 移植约束

- 目标分支 `dev`，所有编辑在独立 Worktree；遵守仓库及用户主工作区保护要求。
- Python 引擎独立运行；`src/rich4/` 禁止通过进程、FFI、网络或绑定调用 C++ 参考引擎。C++ 只允许用于 `tools/` 与测试 oracle。
- 派生程序采用 `GPL-3.0-or-later`；每模块注明固定源码来源并维护 `docs/porting/pygame/mapping.json`。商业内容不因 GPL 获得公开分发许可。
- MKF、EXE、DAT、字型、音视频、解码图片/影片与含素材应用永不提交。原正版来源只读用于导入/研究；正式游戏资源统一在自身`assets/`，测试输出与临时媒体放自身忽略的`.local/`或`userdata/validation/`。
- 正式运行不得使用合成规则、固定结果或假界面替代未移植功能。合成格式样本只用于测试。
- 每局使用 `rich4.random` 的 Watcom 流；Python 标准 `random` 仅可用于测试输入生成，不参与游戏规则。
- 保留 C++ 的编号、字节编码、整数回绕、浮点取整和事件消费顺序。任何修正规则的决定先记录源码证据与差分影响。
- 不将单元测试/资源预览/基础规则批量测试称为完整游戏、自然长局或人工试玩；进度与验收文档伴随代码更新。

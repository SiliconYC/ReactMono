# P4 #65 · 原创纸艺角色与棋子

## 交付和边界

- 继承 #63 纸艺小镇视觉语义与 #64 双地图响应式棋盘，不复制《大富翁4》的受保护角色。四套同源原创矢量形象：**纸狐**（三角耳）、**圆熊**（圆耳）、**长耳兔**（长耳）、**帆鸟**（冠羽与尖喙）。
- 除蓝／珊瑚／紫／金四组颜色外，分别使用**尖耳／圆耳／长耳／冠羽**轮廓及 **1～4 座位数字**；棋盘、开局、当前回合、真人交接、资产总览、玩家状态、终局赢家共用 `characterMarker()`。
- 身份只由已持久化的 `game.players` 数组次序决定（座位 1～4），**不使用**可修改姓名、电脑/真人角色或电脑策略作为角色主键；新旧存档读回无需迁移。更换电脑策略只改变文案，不改变形象。
- 棋子保留 #64 的同格 2×2 定位及 `.piece` 浏览器验收契约；桌面人物尺寸放大，320／390px 自动缩小，仍可看见座位数字；当前操作者增加高亮。
- 游戏引擎的 `player_moved` 事件完成后，仅为该玩家**实际落点**添加一次短暂的上下摆动姿态（`lastMotion` 与 `game.revision` 精确匹配）；不模拟或改写骰数、路径、途经结算。用户开启降低动效时关闭摆动。
- 所有四份 SVG 位于 `site/art/character-*.svg`（不加载外站内容），资源来源、作者、**CC0-1.0** 均登记在 `site/art-manifest.json`；`scripts/build.mjs` 指纹和 `site/sw.js` 预缓存包括所有角色及样式，离线仍可恢复。

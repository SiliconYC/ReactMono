# P3-08 地产抵押、贷款与违约

所有金额为虚拟游戏币，整数字段。贷款和银行为可选功能，旧版状态不会隐式增加贷款字段、债务或利息；网页新对局默认开启。

每块自有地产可抵押一次。每块抵押的额度为出售折价价的一半（向下取整），抵押操作本身不发款。累计未偿贷款不得超过全部抵押额度，提款增加现金及债务相同数额，还款只使用现金且不得超额。净资产为现金、银行存款、地产原成本与升级成本之和减贷款。已抵押地产不产生租金，不能升级、出售；只有在解除抵押后恢复。仅当解除后的额度足以担保剩余贷款时才能解押。

每完整轮次结算一次，默认利率 2%（每轮利息向上取整），先扣手头现金，再自动取出银行余额，仍不足则资本化。资本化后债务超抵押额，则按现有折价价值收回所有已抵押地产，偿还债务；余额退还现金，缺口记录为银行坏账而非其他玩家债务。发生租金短缺时优先用现金、存款、非抵押地产，必要时抵押地产由银行收回后，剩余价值给房东；仍不足则破产。债务、抵押状态、租金及清算事件均为确定性、多人分账。

存档校验贷款额度、归属、轮次及合法金额。含债务存档不能静默清掉债务。回归包含纯逻辑边界测试、多人回合和真实离线 Chromium 存档操作。

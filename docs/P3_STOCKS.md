# P3-10 股票买卖、持仓核算与交易界面（Issue #39）

五家股票均为虚构公司，不接入真实市场、证券交易账户或外部网络。游戏在本地静态网页、PWA 离线模式中运行。旧存档即使已有行情，也不被强制增加持仓字段；首次交易时才生成当前玩家持仓。买卖交易只在掷骰落地处理完的回合结束阶段开放。

- 买入：依当前确定性的每股报价和正整数数量计算金额，从现金一次性扣除成交额与手续费，按数量和含费成本累计持仓。
- 卖出：禁止超持有数量；卖出所得为报价乘股数减手续费。部分卖出的历史成本按股数占比向下取整分配，全部卖出时分配剩余全部成本；成交事件记录已实现盈亏。
- 手续费：每笔成交额的 0.5%，向上取整，每笔至少 1 游戏币。买卖都收取，拒绝非法股数、无持仓、未知代码、越权操作、金额越界和现金不足；失败不写事件、不变化修订号。
- 股票市值：按当前轮报价乘持有数量计入净资产，净资产同时计现金、银行存款、地产购入与升级成本，扣除贷款本金及利息。界面提供持仓股数、累计成本、市值、未实现盈亏，交易消息显示手续费和已实现盈亏。
- 行情使用既有 #38 独立伪随机序列，每轮结算一次，不能因交易重新抽取价格，轮次、报价、持仓和成本均随本地存档序列化。
- 欠租时清算顺序：现金 → 银行存款 → 股票按固定代码顺序整仓出售（扣费用） → 非抵押地产 → 银行回收抵押地产 → 破产。破产玩家不保留股票；其他玩家持仓不变。
- 交易只修改当前玩家，采用纯状态转换、不可变数据结构。存档严格限制代码、数量、成本与破产持仓，拒绝持仓与行情不一致的快照。

验收：`tests/p3-stocks.test.mjs` 覆盖交易守恒、非法参数、成本分摊、四人隔离、旧档相容、100 固定种子和真实回合结算；`tests/browser_stocks_e2e.py` 用离线 Chrome 检测买入→跨轮行情→卖出→备份导出和导入，保留 P1/P2 全量回归。

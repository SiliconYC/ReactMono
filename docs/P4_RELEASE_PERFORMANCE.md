## 修复项目（范围严格限定）

1. **自动存档队列去积压**：原版每次引擎 `revision` 更新都会无限追加 IndexedDB 写事务，过期状态亦逐一序列化、读取旧存档、刷新列表。新版只保留待保存的**最新不可变游戏快照**，已开始的当前事务仍正常完成，后续自动存档以最新状态覆盖；每次提交都沿用现有严格 `serializeGame`、checksum、事务原子性、旧存档版本处理。
2. **更新和读档屏障完整**：`saveQueue` 仍承载到当前最新快照全部落盘的 Promise，Service Worker 用户确认更新须先 `await saveQueue`；读档先取消上个游戏的过期任务、等待旧队列，再恢复当前状态。新开局/重新开局使用 epoch 阻断旧异步保存覆盖新档，不擅自清除本地历史手动存档。
3. **手机触控目标修复**：原公开版「音效 · 关」按钮约 40px 高，未达到本项目的 44px 触摸标准。候选版统一把音效与动效开关/跳过按钮设为至少 44px；允许棋盘在手机纵向向下移动至多 12px，但不允许棋盘自身宽高发生超过 2px 变化、不允许横向溢出。保留全部经济和人类交互按钮。
4. **音效生命周期检查**：在真实 Chromium 使用一次明确用户手势开启原生合成音效，运行快速电脑整局，记录 Oscillator `start/end` 数，确保振荡器全部结束（`onended` 现有资源断开逻辑），没有为跑分关闭游戏音效或关键动画。

## 同机先验对照观察与实际字节

早期 PR #85 完整真实 Chromium 记录已证实，固定种子下双方最终修订号和资产一致：

| 场景 | 已发布原版自动写入次数 | 候选版写入次数 | 游戏状态修订 |
| --- | ---: | ---: | ---: |
| 桌面经典双人 | 49 | 42 | 49 |
| 手机经典四人 | 89 | 64 | 89 |

新方案分别减少约 **14%**、**28%** IndexedDB 写入，完全保留最终状态，且能在 Service Worker 真正断网后读取并核对最终资产；**它只是以上固定种子/浏览器的实测值，不意味着所有负载都有相同比例收益**。

早期 2D 候选编译产物总计约 **486 KB**（其中 JavaScript 约 390 KB、CSS 约 55 KB，六张原创 SVG 总计约 3.6 KB）。2026-10-18 主程序迁移至 React Three Fiber/Three.js 后，发行目录实测 **1,301,710 B**（JavaScript **1,175,136 B**、CSS **114,022 B**、原创 SVG **3,555 B**），可复现明细见本地 `artifacts/main3d/asset-budgets.json`。P4 资源门槛据此调整为总计 ≤8,000,000 B、JS ≤2,500,000 B、CSS ≤180,000 B、SVG 合计 ≤120,000 B、单个原创 SVG ≤35,000 B；该预算只确保当前本地构建留有可检查上限，不代表手机网络、GPU 帧率或长期发热达标。构建使用同源 Vite chunks 并全部进入 Service Worker 预缓存，不再分发未使用的 React UMD 副本。远程 CI 和真实手机实测仍是完整综合验收的一部分。

## 验收工具链与严格阻断

- `npm ci --ignore-scripts && npm test`：现有 P1/P2/P3 和所有 P4 引擎、两图/股票/贷款/地产/卡片/道具、`tests/migration.test.mjs`、`tests/save.test.mjs`、保存协议兼容性逐项保持，新 `tests/p4-release-budget.test.mjs` 对每一个 `dist/` 文件称重、授权校验、SVG 外联扫描、运行时所有模块缓存清单和 fingerprint 完整性做硬性断言。
- `python tests/browser_p4_release_e2e.py`：与旧公网在同一 runner 的公开/候选画面及经济结果对照、完整游戏、两张地图、手机离线 Service Worker 重载恢复、**自动存档修订号相等**及全员资产相等。长任务/内存/加载和帧间隔记录为观察数据；因云端共享主机噪声较大，不用单次毫秒数作自动阻断。
- 原 Chromium E2E 均未删除：`browser_sw_upgrade_e2e.py` 真实双 SW 版本更新→确认更新→离线→读档；`browser_import_e2e.py` JSON 导出/删除/导入/恢复；`browser_saves_e2e.py` 本机多档；`browser_p3_public_final_e2e.py` 真实公开 Pages 全流程；此外仍运行现金/银行/利息/抵押贷款/卡片/医院监狱/股票、2～4 人与地图/旧版迁移回归。
- 视觉审查：CI 附件中的 **公开原版与候选版** 1440px、390px 相同种子完整截图，以及 1280px、320px 候选双图各游戏中/终局截图；核对色彩、棋盘边界与地块标记、2～4 人身份、触控操作层级、无图片加载失败、无 JS 页面异常。像素哈希用于文件完整留证，不因 Linux 字体或非确定性的时间文本不同就机械要求每个像素一致。
- 浏览器无严重崩溃、没有违法规则/经济/存档状态、任意 SVG 无外部图片或脚本、`index.html` 无 CDN 运行时、现有版本化 PWA 缓存内容完整，全部是合并阻断条件。没有真人设备或访谈数据时**不得声称已完成物理手机流畅度或满意度测量**。

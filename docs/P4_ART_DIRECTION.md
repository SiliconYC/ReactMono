# P4 原创美术规范与实际样例 · Issue #63

依赖：#62 基线（`docs/P4_EXPERIENCE_BASELINE.md`）。产品原则：**棋盘和当下动作优先，少即是多**。本 Issue 不重画整张地图、不重写经济引擎、不调整存档格式。

## 两种可落地视觉方向

| 方案 | 棋盘与角色 | 优点 | 风险 | 决策 |
| --- | --- | --- | --- | --- |
| **A 纸艺小镇** | 草绿地块、海蓝底板、暖金强调；原创新几何屋顶和双人物棋子 | 颜色层级自然；地图/按钮能直接区分；无需外置字体/高细节贴图，手机清晰 | 微缩地块必须有独立可点开详情 | **选定为 P4 主方向** |
| B 糖果霓虹 | 紫色主操作、高饱和桃/粉地块、饱满卡片 | 风格鲜明、可作为对照 A/B | 高饱和大面积容易喧宾夺主，视觉疲劳；卡片/地块层次不够明确 | 仅留在视觉样例中做交互对照 |

两者均由同一套语义变量渲染，通过网页样例实时切换。不是两个孤立效果图。后续 #64～#73 只能以 A 为默认，若变更需明确书面证据。

## 可复用标准

- **色彩变量**：`site/visual-tokens.css` 唯一承载 `--rm-ink`、`--rm-bg`、`--rm-surface`、`--rm-primary`、`--rm-water`、`--rm-land`、`--rm-accent`、`--rm-danger`、`--rm-player-a/b` 等语义；对照色板以 `.v-theme-candy` 局部覆写，正式 UI 默认使用纸艺小镇。
- **字体**：无需第三方在线字体；系统中文字体优先，正文原则 ≥13px、主要按钮 ≥16px，显著数字 20px 起；细节缩略字不代替可点开的正文信息。长地名优先省略、点击后完整展示。
- **角色识别**：两位玩家分别用蓝色微倾方角棋子与珊瑚色圆形棋子；形状与颜色双编码，禁止仅凭颜色区分所有权。
- **棋盘**：可交互地块保留按地图定义的行列位置及路径；地块类别以统一小屋/金币/菱形图形提示，当前选中边框与所有权不同色。小屏重点是棋盘和即时操作，其余信息转向地块详情。
- **卡片/资产**：一个紧凑信息板展示现金/净资产和选中地产信息，强调真实经济语义；不可用装饰性卡片占据棋盘首屏。按钮高度至少 44px、焦点轮廓明显。
- **响应式**：样例桌面棋盘与控制面板双栏，≤770px 自动单栏、≤380px 隐藏微缩格内非必要文字，完整地名可通过点击读出；手机页面必须不出现横向滚动。
- **动效**：短距离、低强度，只用于选中/反馈，不用夸张运镜；`prefers-reduced-motion: reduce` 关闭过场和漂移。
- **无障碍**：地块 button 有完整中文 `aria-label`、选中 `aria-pressed`；操作反馈 `role=status`；高对比字色；系统缩放不能使主按钮不可达。
- **原创/授权**：`site/art/house.svg` 与 `site/art/coin.svg` 是本轮原创矢量；自绘棋子与板块直接由 CSS 生成。`site/art-manifest.json` 逐项记录用途、作者、来源、CC0-1.0 授权状态，无未登记的外部角色、字体、图像或音乐。**禁止**直接使用《大富翁4》受版权保护的素材。

## 真实网页交互与资产管线

- 正式游戏页尾可以打开 `/ReactMono/visual-lab.html`。样例的每一次掷骰、购买/放弃地产、结束回合、银行存 50 都经过正式 `createGame + applyAction` 校验；能够切换经典/海港地图及 A/B 样式；独立初始化，不读写现有游戏存档。不是 MP4、截图、或纯 CSS 动画伪装的游戏。
- `src/ui/visual-lab.tsx` 与正式核心均由同一个 TypeScript 构建流程输出至 `dist/ui/`；`scripts/build.mjs` 将 HTML、CSS、原创 SVG、资源许可清单归档，并将它们加入静态内容指纹。
- `site/sw.js` 与构建结果将页面、CSS、图标、运行时模块纳入 **同一版本** 的预缓存；离线可访问，不增加服务器、CDN 或账户。正式页面样式变量也被引入，逐步落实统一语义，但不推翻 #62 审计的布局基线。

# P4 #68 原创离线音效

使用原生 Web Audio 即时合成正弦/三角波，**没有外部音频素材、第三方许可或网络请求**。骰子、移动、收钱、付款、卡片、特殊设施、终局分别使用不同短促音型，7 类事件归纳，代码原创按仓库许可。

默认**静音**，在用户明确点击「开启音效」后才建立 AudioContext，音量可调。本机独立保存 `reactmono-audio-enabled`、`reactmono-audio-volume`，旧游戏存档格式、离线引擎和玩家资产均不变。重载若之前开启，下一次合法用户操作唤醒声音，不自动播放。后台页面不发声；浏览器不支持/拒绝自动播放时保持游戏继续。限制最低连续间隔 65 毫秒，声音最长不到 0.6 秒，不用音乐时长控制回合或计时。

本轮有意**不增加循环背景音乐**：游戏需要策略决策与多人轮流交谈，持续声底会干扰。只保留对玩家行为有意义的短暂反馈。没有录音、下载、声音版权风险；因此静态 PWA 断网运行无需缓存任何音频二进制资源。CSS 仍加入内容指纹与 precache。

验收：`tests/p4-audio.test.mjs` 检查 7 类声音、纯合成和离线资源；`tests/browser_p4_audio_e2e.py` 在实际 Chromium 桌面、手机测试默认静音/点击启用/实际生成振荡器/音量更改/重载/离线/关闭音效。完整保留 P1～P3 与 P4 #62～#67 引擎、存档、UI 和离线验证。此为机器测试，不冒充真人听感评测。

## P2 能力退出门槛

1. GitHub Pages 上的整个运行时无必需 CDN，首次缓存完成后断网可启动且玩完一局。
2. IndexedDB 多档位可以保存、关闭重开续局、自动保存；失败时显示清楚的简体中文提示。
3. 从本机导出 JSON 再导入能够恢复状态，格式损坏或冲突不会破坏已有存档；旧版兼容性有测试证据。
4. 地产升级、基础事件/卡片与基础电脑行为相互兼容，合法对局能在有限回合内结束。
5. 保留 P1 全套测试，至少 100 个固定种子无界面模拟，以及真实浏览器含断网和文件操作的完整对局测试。
6. 记录部署、测试结果、真实缺陷、回归与回滚路径；不能只靠 PR 合并或 Pages build success 自称验收。

## 未晋升的方向与理由

- 股票、银行、高级电脑策略、多地图、大规模卡片/建筑、精细美术和完整音效：属于 P3–P4 或需更多证据的研究，不在 P2 一开始建 Issue。
- 账号、游戏服务器、云存档、跨设备自动同步、国际化：已被产品约束排除，不能借 PWA/存档任务引入。
- 自动化无人值守调度系统：需独立验证实际权限与运行条件，不把“建立 9 个 Issue”算作实现 AI 长期自主迭代。

本轮仅创建 Issues 与更新规划文档，**未改动任何游戏源代码**。任务完成后由 AI 自行测试、PR 合并 `dev` 并发布 Pages，无需每次再征求所有者确认；遇到真实失败或权限阻塞要保留证据。

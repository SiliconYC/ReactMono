# 大富翁 2026 交互与显示修整

2026-10-22，基线 `7cbab7c`。本次来自所有者十二项直接反馈，以青柠游园验收，共享缺陷在通用层修复。纯静态、简体中文、统一投影受影及 `dev` 集成约束不变。

## 根因与设计

- 镜头：`Scene` 在移动/租金演出时强制跟随，`MeasuredWorld` 把每次操作栏高度变化传给相机，偏移未插值；人物移动结束才补座位偏移。删除演出对用户相机模式的接管；同一视口使用固定操作安全区，镜头只对真实跟随目标平滑移动。手动旋转冻结缩放，保留自由浏览位置。
- 角度：俯仰从原 `30°–70°` 放宽到 `12°–82°`。相机深度、地表覆盖、阴影相机统一按低角度计算；数字压缩补偿有足迹上限，不能把编号拉到邻格。
- 建筑：青柠共墙侧面多个面落在同一深度，改为合理的连续墙体与独栋窗框/玻璃分层。主人颜色只用于门楣、遮棚和饰带等识别部位，屋顶/主体保持原色。路砖轻混主人色，移除产权椭圆。
- 朝向：初始化、读档、批量模拟之后按地砖通向下一格的实际世界方向摆放。移动时始终包含座位偏移，避免落地最后一帧平移。
- 按住查看：左键/触屏静止按住 `400ms` 后显示当前位置提示，松开即隐藏；短击不打开常驻层。超过 `7px` 移动、多指、旋转、失焦、取消或拖动时取消。土地/房屋显示名称、街区、产权、等级和通行费；角色显示现金、存款、贷款、地产及状态，不泄露调试字段。键盘提供可按住查看的等价入口。
- 控件：右上保留一个清楚的紧凑地图工具条，常用全图/跟随切换与工具展开；缩放、回正、小地图和说明在展开内，去掉重复按钮。控件开合不改变相机取景。
- 回合：真实移动/结算/建设演出结束后自动继续，无需额外点击结束。可选建设与商店选择仍等待决定；提供明确“管理资产”暂停入口，弹窗/隐藏页/提示按住期间不抢回合。所有定时操作绑定局面身份、玩家和修订，旧局回调不得影响新局。
- 命名：产品统一为《大富翁 2026》，保留晴湾等真实地图名字。

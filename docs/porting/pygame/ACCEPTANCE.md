## 失败、修复和未解决问题

1. 环境配置首次安装失败：Hatchling 无法从发行名推断 `rich4` 包。根据构建错误将 `src/rich4` 明确写入 wheel 配置，重新同步成功。不是游戏缺陷。
2. 默认 Conda Python 3.12.7 在 pytest 导入 `readline` 原生扩展时段错误（退出 139）。`-X faulthandler` 定位；改用已有独立 CPython 3.12.13 环境后运行成功，未通过关闭测试绕开。
3. 首轮差分每帧重复打开大 MKF，耗时明显；主动中断并保留本机部分报告。改为测试专用 C++ 批量适配器，每包读取一次，第二轮全部通过，177.551 秒。中断不是通过，未将其计入成功结果。
4. 预览窗口在独立 Python 进程运行且有画布输出，但桌面工具绑定超时。尝试本机仅用于验收的 `.app` 入口后进程可识别，仍无法取得 AX 状态。此障碍尚未解决；未记录键鼠验收成功。该入口仅启动 Python 解释器，不实现游戏规则，不进入交付运行时。
5. 自审发现预览器按游戏原锚点在 `(0,0)` 绘制人物，正原点人物会裁出窗口。新增真实 Surface 像素测试观察失败后，把预览器小精灵置中；游戏图形库保留原锚点契约，35/35 通过。
6. 源码语法清单 28 个文件存在解析错误节点，含其他语言与语法扩展；没有把 1708 当作语义精确总数或移植覆盖百分比。

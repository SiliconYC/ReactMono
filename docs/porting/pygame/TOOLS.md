# 十三道具与交通、传送

固定来源`src/tools.cpp`、`include/rich4/tools.hpp`及原测试，Python对应`tools.py`。十三个处理入口、原选择位域、收起交通均已翻译；外部机器人、爆炸、房屋升级、骰子推进及回合恢复仍需真实GameSession接入。

## 选择与消耗

道路、普通地、设施、角色和物件目标保留原编码，双阶段传送保留原选择位域。不在运行模块生成测试目标、固定骰点或替代规则；使用入口接受真实输入并拒绝取消、缺库存、无效目标或缺回调。控制标志未活跃并不会被工具模块额外拒绝，调用者资格由原会话负责。

装备机车/汽车先把原交通返还**玩家库存**，不归还共享供应，数量保留字节回绕；新交通道具从玩家库存扣除并保留在装备中。工程车保存原交通/骰数，设交通`0x1f`和一骰；原交通低两位已为3时跳过重复装备。收起交通仅按完整字节1/2返还机车/汽车，不凭保存字段恢复，也不返还工程车，不能自行增补规则。

路障、雷和定时炸弹分别使用原十槽区间，保留节点占用检查、原首非零邻居朝向和消耗顺序。物件种类/节点/剩余日/附着信息在朝向计算之前写入，因此损坏邻居可导致部分状态变化后拒绝；不能在失败时静默回滚。

## 传送

搬地只转移业主、等级、连锁/设施类型和租期，不移动地价/位置/名字/临时状态，也不复制目的地残值；原地残值清零。不同土地类型拒绝，目标须原无主且无建筑。

附着对象目标转换为其承载玩家；角色低位掩码选择最低槽。目标道路按原邻居次序和禁行位找最接近原朝向的路径，并保留并列顺序。原占用位清除，新节点设位；普通玩家所有附着物一起移动，特殊角色另行处理。方向差的无符号回绕保留，损坏方向字节不被Python负数比较改变。

自身传送的前置回调在重新读取玩家状态之前执行。物件传送先清旧节点字节、设新位置与新节点对象位，最后计算朝向；这同样可能产生部分失败。

## 回调顺序与真实依赖

机器人：扣库存→说话→真实机器人行动。遥控骰：仅人类说话→真实骰子回调→扣库存。时光机：说话→尝试真实回合恢复→从恢复后的`header.current_player`扣道具，不能从原调用者或Python记录派生槽位扣除。恢复失败仍已说话但不消耗。机器工人/飞弹/核弹在确认真实回调后先扣、说话、再执行外部效果；传送应用后扣库存并说话。

上述回调缺失时明确返回`支持=False`，不会以空函数、固定结果、伪爆炸或伪恢复提供可玩假象。差分里的观察/状态注入钩子属于测试输入，尤其修改当前玩家并不等于实现完整时光机。

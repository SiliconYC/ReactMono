# 拍卖会话

固定依据 `src/auction.cpp` 与 `include/rich4/auction.hpp`；Python 对应 `auction.py`。这是可暂停的规则会话，尚无拍卖 UI、播报和动画。对象存在期间调用方不得修改关联 World 或 RNG；真实游戏中的挂起/恢复仍须集成验证。

## 规则与数值

- 起价先按 `地价 × (等级 + 2) / 2` 截断，再乘物价。玩家现金必须严格高于起价才有参与资格；酒店、消失、监狱、医院、睡眠、梦游的非零状态均排除，包括高位释放标记。银行余额不参与资格或支付。
- 活动玩家记录先压紧，不合资格者保留空位；最后一个合格记录首先行动。控制标志恰为 `1` 才等待人类，`&6` 非零者消费两次估价随机数。
- AI 热情、稀缺和上限比按源代码落 binary32。估价乘积先精确整数乘两个 binary32，再按 x87 64位有效数舍入/截断；复用 `numeric.py`。第一次整数×binary32最多55位、第二次最多79位，因此与源 `original_product` 单次64位舍入一致。初始价与后续物价乘法的32位回绕保留。
- 临时放弃在下一次加价时清除；永久退出保留记录空位。公开决策包含退出掩码和所有合法行动。已结束会话拒绝再次推进或出价，不重复支付。
- 成交现金付出、卖家银行收入；无卖家则进入公共基金。累计收支按32位回绕，建筑等级和临时状态保留。仅无主地产新租约设置到期日；原打包月份加法不规范化日，因此可产生二月三十一日。转售不重新起租。

## 自动验证

[跨语言报告](evidence/auction-differential.json)：八图各100组，共800组、5554个初始/逐步快照，包含166次构造异常拒绝和317次成交。每步比较全部公开会话状态、五个槽的电脑估价查询、人类合法行动/退出掩码、RNG及完整DAT。输入覆盖人类/电脑/混合及其他控制位、现金/物价边界、资格状态、卖家、租期覆盖与无效地产编码。合法价格与布局来自真实地图，资金/所有权/状态变化是显式测试准备，不进入正式游戏。

另有2000组电脑拍卖终止、买方现金非负及现金加公共基金守恒检查。这是独立不变量测试，不是2000场游戏长局。局部边界覆盖最后合格玩家先行、恰好支付全部现金、全放弃无成交、加价清临时放弃、商业之外的设施租期和重复结算拒绝。完整Python测试92/92、Ruff通过。

```sh
uv run --project pygame python pygame/tools/differential_auction.py \
  --source /path/to/pinned-cpp --build /tmp/rich4-cpp-core \
  --map /path/to/map.mkf --report /tmp/auction-differential.json
```

未验证：真实人类拍卖窗口、计时播报动画及其表现随机消费、嵌套卡片/魔法拍卖恢复、完整回合中的地产结算。差分一致不等于证明原官方游戏行为。

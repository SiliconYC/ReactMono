# 原卡片电脑策略与持续参数

固定来源`src/cards_ai.cpp`、`include/rich4/cards.hpp`、`tests/cards_ai_tests.cpp`，Python对应`cards_ai.py`，复用已差分的卡片用法/回调、软件x87、库存、股市与原前瞻接口。策略只选择真实卡片用法，不消耗手牌或执行假事件；后续由`cards.py`及GameSession执行。

## 八槽访问与三参数记忆

控制标志含`6`位且卡片策略含`1`位才访问。手牌超过八张随机起点并回绕，随后取八槽；不超过八张从0开始，碰到0停止，即使后面还有非零卡。攻击性减救援策略达到2跳过，等于1抽三分之一，按原次序消费。

三个32位参数跨调用保留，谓词没有赋值时不能擅自清空。一般扫描更新参数2为实例数；召唤卡直接取得扫描表，却不更新该参数。停留卡某分支会成功但不写目标，转换卡普通地产分支也可能沿用旧选择。最终解码保留原最低角色位优先、物件与地产边界，股票0和没有目标不能混为一谈。

原电脑不主动选择换屋、转向及18/19/20/21被动卡，共六种；其余24种已覆盖实际选择结果。这并不减少`cards.py`对人类主动卡和被动卡依赖的支持范围。

## 关键原行为

- 敌手仅取最高有符号正敌意，没有道具策略中的随机回退。附近复合角色编码展开后保留重复项，部分策略按槽位而非扫描顺序选择，均按源保留。
- 强购辅助函数在没有正敌意时提前退出，连一般设施分支也不可取。怪兽优先敌手设施，再选其地产；没有敌意时三级普通地产不足资格，设施仍优先。
- 天使街区计数16位回绕，恶魔的各业主楼层/数量按字节回绕；连锁地产和NUL名称比较按源处理。抢夺以原卡价及攻击性选择，不以新评分替代。
- 送神先检查有效附身神明；若是好神便不会继续检查炸弹。召唤按最近可见对象选取，后按**对象ID**判断友善，不能改成种类判断；距离有符号32位平方和溢出产生NaN时不命中。
- 红/黑卡按持仓成本而非市值，使用软件x87整数转换；电脑排除停牌，黑卡回避自身持股、优先敌手再公司大户。
- 涨价卡设施评分误用上一次地产游标或八槽遍历终点；终点0时仍写目标却返回不使用。此类旧参数影响后续调用，保留而不纠正设计。
- 查封和龟行的前瞻通过原接口取得，先自身再扫描其他玩家，分岔/机会/租金顺序保留。规则随机流由调用方传入，没有另加概率。

# 主动卡片、目标与被动反制接口

固定来源`src/cards.cpp`、`include/rich4/cards.hpp`及原测试，Python对应`cards.py`。全部26张主动卡处理器、18号复仇卡的内部触发和19/20/21号被动卡依赖分发已翻译；电脑选卡访问顺序在独立`cards_ai`，不混入手动操作。完整被动免罪/嫁祸/免付由原GameSession拥有，当前仍待移植。

## 类型、目标和选择

`目标种类_类`保留角色/地产/股票/物件/卡片/道具编号，目标值沿用原零起始或地产/物件代码。`卡片用法_类`的目标/库存选择用`None`表示未选；数值0不是取消，设施重建类型0有效。结果区分已用、取消、非法、缺回调，已消费后仍可能返回非法或抛出等待选择，不能统一回滚。

人类目标按原附近实例列表过滤；正式UI必须提供真实原视口扫描，不允许在卡片选择中随意平移相机。电脑显式目标参数不走人类视口钩子。24/25号股票卡直接列全部股票，人类卡片模式不套用普通交易的停牌/涨跌停限制；休市检查仍保留，实际人类应用可能先后调用两次休市回调。

## 原数值和字段

均富/均贫先按32位有符号回绕加总，再向零除；地产成本也是逐层原回绕。抢购卡、拍卖卡的地产敌意，以及黑卡的持股损失敌意，保留原binary64低32位误当整数的ABI行为。黑卡先执行原binary32价格减法，只有持股不为0时才进入有限软件x87运算；无人持股时异常报价差不会让操作提前失败。

`卡片产权_类`代理原引用成员：业主、等级、连锁/设施类型、临时状态和租期实时读写世界；基价/造价在代理创建时取值。回调改写业主后，后续台词仍读取新值。换地只换业主，不换租约/楼层；换屋只换等级/类型。原同街名称在第一个NUL前比较。拆除、怪兽、天使/恶魔作用范围和酒店释放依赖沿源码，保留字节回绕与先消耗后效果的顺序。

抢夺道具仍按**卡片价格表**计算敌意；道具接收因满9个或共享供应回绕失败时，原受害库存和卡片消耗/抢得表现仍照源码发生。冬眠、梦游与复仇保存/归还交通，初次梦游的步行玩家保留已配置骰数，而复仇梦游总是重置一骰；冬眠累计字节回绕。停留自用置`0x80`，龟行自用两天、他人三天。

请神按原实例扫描顺序，以回绕的32位平方和、开方后binary32距离选最近者，并列保留先出现者。平方溢出到负数时距离为NaN，按原比较跳过，不在Python调用开方时抛出新异常。

## 回调与被动卡

卡片语音保留说话人、行号、卡号和表情；重建/抢夺在选择前说话，取消仍已经播放。抢得回调保留是否预设库存选择，供原电脑抢得框和人类库存界面区分。复仇弹卡图→消费18号→持有者说话→使用者受击台词→反作用次序均保留。

其它卡片防御、免付、嫁祸、监狱、神明、拍卖、付款、升级、转身和真实附近扫描必须接入原拥有规则的会话。观察/注入钩子不是完整规则，缺依赖显式返回缺回调；手动模块本身不抽电脑专属随机数。

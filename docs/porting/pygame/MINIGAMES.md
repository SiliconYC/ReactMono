# 三个小游戏逐tick规则

固定来源`src/minigames.cpp`、`include/rich4/minigames.hpp`、原小游戏测试及已有UI研究；Python对应`minigames.py`。本阶段实现真实输入与逐tick规则，正式界面接入另记；不返回固定分数，不调用C++运行后端。

## 时钟、随机流与表现接口

节点6为企鹅、7为气球，其余映射天降，定时器分别100/100/50ms。开场倒数、READY/GO模态片、游玩、分数停留、关闭五阶段保留。准备阶段的tick不推进规则，只有准备片结束调用开始；完成后重复tick/开始均保持状态。

每个小游戏持有共享Watcom流的私有副本，32位计数每次抽样；真实会话提交分数与计数后必须按同次数推进主流。场景为有序资源/帧/锚点/16.16缩放指令，声音请求区分播放/循环/停止；取声音会清空队列，表现本身不抽随机数。

企鹅原9×9表有64有效格，28宝物按3炸弹/12金币/3粉钻/9蓝钻/1钻石放置，每个恰好一次抽样。原DDA按最大轴移动、无效格滑行后重新瞄准，四帧移动和挖掘、冰屋遮挡、宝物弹出、炸弹提前结束和分数背景盖章标志均保留。计分为钻石20、粉钻12、蓝钻8、金币5；只在放置抽随机数。

气球十六槽按原概率和可用巷道生成，新球下一tick才画；爆裂三tick、原描绘框裁切与点击框不同，点击可同时弹多个重叠球，每个未命中活动槽分别错音。问号六效果、冻结倒数先减、速度变更、翻倍/减半/普通加分封顶顺序和结束清场均保留。

天降按真实人物帧框接取，使用软件x87漂移、先落binary32比率后求位移/缩放。财神/鬼怪状态、抛投概率、接者每tick十像素/八像素死区、方向保留、炸弹循环音/爆炸时长与结束额外一步重绘均按源移植。接住炸弹后不凭直觉改动原计数/清场顺序。计分为箱10、袋5、金3、币1。

## 差分证据

九项单测从缺模块失败开始：节点/时钟、28次放置、模态阻塞、可达性/安全挖掘、炸弹/结束点击、气球真实生成/错音/随机重放、天降精度/图框和真实移动结算。完整Python236/236、Ruff通过。

```sh
uv run --project pygame python pygame/tools/differential_minigames.py \
  --source /path/to/pinned-cpp --build /tmp/rich4-cpp-core \
  --assets /path/to/Rich4 --report /tmp/minigames-differential.json
```

[报告](evidence/minigames-differential.json) 304条完整时间线：企鹅100（含全部64初始目标）、气球96、天降108（十二人物、三种子、三操作方式，外部原精灵帧框）。107300命令包含69491次tick、31308输入、4864辅助探针和1637次建立/开始/结束点击。五阶段、全部公开状态、每帧绘制指令/顺序、声音请求、分数/计时、RNG状态/次数逐步相同；108个不足五帧的异常构造也保留旧游戏并一致拒绝。

气球全部十二种均实际弹中，共1921次；42个问号包含全部六种效果（3/8/8/3/10/10次）。企鹅挖出金币56、粉钻14、蓝钻46、钻石6，炸弹时间线另有实际声音/提前结束；天降接中炸弹36次。累计163173次规则随机调用，准备/完成的重复操作也在对照中。

输入由测试操作策略生成，不改内部状态或注入分数；使用可见预览记忆、随机点选、追逐宝物/炸弹和左右移动等策略。该证据是完整**小游戏逻辑**时间线，不是自然主游戏长局，不是人类操作或像素验收。绘制指令相同也不能证明最终画面已经相同。

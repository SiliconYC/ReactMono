## 函数覆盖与实际代码规模

原矩阵的 1,231 条对应全部保留其组件阶段状态与证据，新增当前集成说明；其余 477 条经过分类：50 条内联属性/值比较/包装已有对应，280 条是参考测试函数，10 条是 C++ 禁止复制声明，137 条为移动包装、开发/研究/自动验收工具、语言移动构造及不可达旧编辑器等非桌面正式功能。**1,281 条有 Python 对应，427 条明确不要求逐函数移植；不是“1,708 个游戏功能全部通过”。**

`src` 的 620 个定义均已有对应，正式屏幕及宿主也纳入矩阵；没有用“核心已迁移”代替完整前端。头文件的默认相等比较由 `dataclass`、getter 由属性读取、包装由直接调用承担。原 `editing_amount_` 只初始化/清为空，没有启动赋值；正式数额输入使用 NumberPad。画廊的设施预选、预置竞价不是正式游戏缺失功能，未将其做成固定结果入口。移动 APP 后台事件不等于桌面失焦；本交付未移植移动安装包/挂起接口。

运行时 152 个 Python 文件、33,637 物理行；测试与真实强杀 worker 共 100 个 Python 文件、9,165 行；研究/转换/验收工具 84 个 Python 文件、24,021 行。统计包含空行、注释和固定查找表；C++ 测试适配器另计，不装入游戏。行数不是功能覆盖率。完整规模和分类机器记录见 [交付元数据](evidence/completion-audit.json)。

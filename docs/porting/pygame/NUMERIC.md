# 软件 x87 与股市数值契约

参考固定 `include/rich4/legacy_float.hpp`、`src/stocks.cpp` 及相应测试。Python 的 `float` 为 binary64，不能直接替代参考的每次64位有效数舍入。

## 扩展数

`numeric.py::扩展数_类` 用整数保存有效数、二进制指数和符号。加减保留 guard/sticky 位，乘除在每次操作后归一到64位有效数；单精度和双精度落盘分别做 ties-to-even。整数转换向零截断，溢出返回原 x87 integer-indefinite `INT32_MIN`。主机浮点只用于解析输入的 IEEE 位与装载最终精度结果，不承担中间扩展运算。

[自动差分](evidence/numeric-differential.json) 比较40900个表达式的扩展内部状态、binary32/binary64存储位、整数转换与异常范围，和固定 C++ 软件模型一致；**不是**原 EXE 或硬件 x87 的新采样。四项局部测试另覆盖 binary64/x87 中点、额外有效位、负数截断、除零及错误类别。

## 股市

`stocks.py::股市_类` 保留以下细节：

- 买市场股扣银行，一级发行扣现金且先截断公司估值除以10000。
- 成本基准经前持仓成交额截断、32位加法回绕、扩展除法和binary32落盘。
- 先移除再插入股东；持股相等时保留其他既有股东优先级。
- 股价档位依据未最终舍入的候选，按相对涨跌额截断，不将绝对股价简单吸附到十进制网格。
- 财富每加一支股票前先将累计整数落到binary32，即使持仓为零；地产不乘物价指数。
- 限额每支可购股数超过1000才消费一次随机数；休市不改变任何股票或随机位。
- 日行情、强制行情和停牌/新闻分支严格区分；强制行情覆盖上一个股史槽，不推进游标或消耗随机数。

[股市差分](evidence/stocks-differential.json) 比较20288个股价输入，并在四张真实地图初始世界、三种种子上执行2400个模块动作；每步比较返回值/拒绝类别、完整世界DAT字节及随机状态，510个拒绝动作也一致。这些动作不是完整回合、自然长局或图形交易验收。

## 已发现的源码/注释边界

首次价格差分触及最小正binary32（位值 `1`）与零幅度：C++ `adjusted_price` 的注释声明有限域 `[0,10000]`，但内部 `Extended::single` 只支持正常浮点值，会抛出 `std::out_of_range`。测试适配器最初只捕获 `std::invalid_argument`，因此中止；[首次失败](evidence/stocks-initial-failure.json) 保留，不计成功。最小反例为原输入位 `1 0`。

修复的是适配器与Python异常类别表达：`数值范围错误_类` 区分目标正常浮点范围错误和非法输入/除零，属于 `ValueError` 子类。未修改固定 C++，也没有把小数结果伪造为合法报价。随后全部价格/动作差分通过。

另一个源码边界是可玩验证允许有限股价 `[0,10000]`，但 `player_wealth` 拒绝非零且小于1的报价；当前保留各函数实际检查，而不偷偷扩大或缩小规则。正常开局和行情钳制后的报价在支持范围内。涉及异常旧档时，须保留具体调用与失败依据再决定是否修正参考行为。

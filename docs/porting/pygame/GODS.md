# 神明、地上对象和金钱转盘

固定来源 `src/gods.cpp`、`include/rich4/gods.hpp` 与原测试，Python对应`gods.py`。库存、软件x87、原日期和世界使用已经移植的模块。神明对象的编号与种类分别保留；例如第二个乞丐对象编号16、种类15，不能互换。

## 原数字转盘

`金钱转盘_类`对应原十个阶段。每次`api_步进`是一帧，正式表现应按原名义30ms驱动；输入停止只把阶段1置2，随后步进进入3。阶段1/2每十帧刷新四个原随机数字，奇数位置表示数字之间，继续逐位转动和减速；小神省去千位显示，但刷新时仍消费四个随机数。电脑第40帧触发停止，之后各位按原周期渐停，阶段9等待40帧，完成后重复步进不再改变状态或随机数。

`api_自动金额`实际执行这套状态机，不使用另抽一次随机数或固定金额替代。正式人类交互尚未接入；测试中给定金额是边界输入，另有使用完整自动转盘的回调路径。

## 附身与脱离

附身先检查旧神移除、数字转盘和融资依赖，再把新神节点置零，避免阻碍旧神再生；随后移除旧神、设置新神对象/玩家关联、清来源节点对象字节、加有符号16位运势修正。恶神先说类别22，再播放现身、到达标题，最后执行效果；离开是移除→音效54→上升表现→必要的类别23，缺席者不说离开语音。

财神按原付款人/收款人和标志逐活跃玩家结算，循环前逐项检查终局；大财神现金和累计收入回绕。福神送一/两张卡，奖品语音使用`header.current_player`，并非附身目标；穷神随机弃卡或按原交替槽位丢半手。乞丐归还交通工具、卖尽库存/卡片但忽略卖出点数，不增加玩家点券。

`神明回调_类.移除物件`必须在真实会话中撤回旧运势、归还/再生对象；本模块没有用简单清零冒充完整移除。付款须接入实际融资/破产。升级/降级须执行真实房屋规则；表现钩子不得自行消费规则随机数。

## 地上对象和地产后置

普通玩家只在停靠时接触大部分对象，路障经过即停，乞丐不能步行拾取。空供应赠品留在地图上，这与槽4特殊角色先移除赠品不同。狗固定移除编号11，按完整交通字节是否为零判断受伤，而非仅看交通低两位；定时炸弹附着38天，设置部分状态之后才访问玩家节点，节点损坏可能在部分附着后报错。

地产后置按玩家神明**编号**9/10/12判断：天使升级、恶魔降级、土地神取得产权。土地神敌意保留原ABI错误：软件x87先计算比例，再乘回绕基价与物价，落到binary64，取低32位作为有符号敌意参数；不能替换为数学金额。原无主地按租约模式加打包日期，保留2月31日等原规则结果，不能用现代日期规范化。

成功购地/升级后的福神回调另行执行；升级结果最低位决定是否应用，`0x80`决定固定封顶语音15，否则消耗一次随机语音。

# 原股票电脑买卖策略

固定来源`src/stocks_ai.cpp`、`include/rich4/stocks_ai.hpp`及原测试，Python对应`stocks_ai.py`，复用已差分的软件x87、股票结算和世界模型。买卖入口包含自己的概率/投资比例/休市/贷款门控，GameSession不能再提前过滤或额外抽随机数。

## 门控和贷款

玩家和股史游标先验证，不消费随机数。买入先抽原三分之一概率，再检查比例/休市，即使休市或零比例也已有一次抽样；到期不足15天则不买。预算按回绕持仓值、现金加银行与投资比例计算，只使用银行可用余额。

卖出先按原到期日和流动资金判断紧急。紧急时不抽概率，休市也没有概率抽样；非紧急则即使休市仍先抽一次。打包贷款日用该年月1日加`日-1`，保留11月31日等价于12月1日；零到期日对应原日序-1，不当作永不到期。日期元组在世界头为日/月/年。

## 评分、精度与排序

公司评分使用利润、每万股整数估值、现价/成本、竞争业主持仓与可取得股数，阈值均保留原扩展精度。公司卖出中的份额是**全体数量除以自身数量**，不是直觉上的自身占比。普通市场用6/24期股史，忽略正负零，每次累加及均值落binary32；持仓总价值则先把上一整数总值落binary32，再做本次x87乘加和整数截断。

普通卖出零成本比率显式为正无穷，评分转整数采用原不定整数`INT32_MIN`和后续32位回绕，不能直接跳过。原趋势字段有按有符号IEEE位比较的条件，不以数值比较替换。

十二候选使用Watcom小数组排序的间距3再1，外层也按间距推进，严格分数比较会改变并列项的相对次序；不能替换为普通稳定排序。买入按排位逐候选抽样，最多成交一股种；卖出每次重新扫描最高分，非紧急一笔，紧急则继续到无候选或达到贷款的原`1.1`阈值。

实际成交调用完整`股市_类`，记录数量、真实费用/收入和公司易主；没有固定买卖结果或假交易。

## 验证范围

差分工具除真实买卖入口外，在测试适配器中包含**固定C++源文件**观察私有评分/排序，不改参考代码。私有探针先套用公共玩家/游标验证，避免对C++数组越界输入执行未定义行为；不宣称这些保护是原私有函数自身已有的检查。原正式Python模块不导入或调用任何C++。

固定来源为`3f4209a7dfb5b2f20799bf54e6c03c5faa11c557`的`src/game.cpp:1504..1710`、`3085..3299`与`3379..3565`。经济基础模块不重复说明，见[数值](NUMERIC.md)、[服务](SERVICES.md)、[日期/彩票](CALENDAR_LOTTERY.md)和[原股票电脑](STOCKS_AI.md)。

## 已实现行为

`game_finance.py`按原次序实现支付/敌意/付租者选择/租金、破产/终局/保险、到期贷款/借还款/融资、银行菜单/电脑资金调配、财富/物价/分红/月结奖项与租期老化。防御、收容、物件及拍卖使用同一会话回调，正式运行不调用C++。

- 扣款先按标志选择现金或存款，钱不够先破产再累计支出、向接收者入账；公司可负债付款，公共基金及账户保留32位回绕。
- 所有人类离场即结束；仅剩一个活跃人类才有赢家。人类托管保留人类位，不能以全电脑配置冒充自然长局。终局破产按原提前返回，尚未清理的地产/库存保留。
- 免付后重新计算嫁祸门槛，强制缺席仍可由原衰神编号14/15承担。敌意按有符号值比较，正增量即使回绕也解除盟约。
- 贷款仅在到期当天收取。电脑还清保留旧到期日，再借款也不更新非零日期；非法或已过日期不补收。融资上限计算全部其他存款，撤款追缴只计算活跃存款，银行公司取最后一个拥有者。
- 银行禁贷同时隐藏提款选项；不能擅自按常识修正。电脑银行的比例落为binary32，差值保留binary64，0.9/0.1常量也为binary32，结算使用软件x87整数转换。
- 公司盈余可为负，分红先存完整显示快照再结算，持股比例先落binary32，公司仅在总持股非零时清资金。负存款先扣现金，仍不足则破产。
- 月息按原x87计算，超界保留`INT32_MIN`，不改为钳制。月报记录利息前/后的不同字段，累计值连非活跃槽也清零。悲情评分排除全部并列最高者，并要求正的次高分。
- 租期是原打包加法，1月31日加一个月可得到2月31日编码，并不自动钳为合法日；临时状态到最后一周期同时清低位，租约到期保留建筑。

数据模型中的`DividendRow`原来误多定义公司字段；新非空分红测试先失败后删去，现为原股票编号、盈余和四槽派发额。租金公告盟友字段、银行单精度接口名也由定向失败用例修正。

## 自动验证与界限

十九项金融定向测试覆盖上述边界。金融探针复用真实世界和事务/表现组件，直接调用原私有金融入口；测试编译包含固定`game.cpp`并用`-fno-access-control`，不改参考源码。

```sh
uv run --project pygame python pygame/tools/differential_game_finance.py \
  --source /path/to/pinned-cpp --build /tmp/rich4-cpp-core \
  --assets /path/to/Rich4 --report /tmp/game-finance-differential.json
```

[差分报告](evidence/game-finance-differential.json)：八图三种子77455命令，其中10560次金融入口、8712次明确重置，其余为账户/公司/日期/持仓准备和清显示队列。23类入口均实际调用；每步完整DAT、RNG、阶段/时钟/选择/记忆、事件/效果/决策、非空月报全部字段、胜者与银行续行标志一致，没有把不匹配状态过滤掉。

该专项夹具明确令神明未附身、特殊角色不活跃，且不制造超过三块地产的破产拍卖；它没有覆盖这些真实回调。后续公开会话自然差分及引用行为见[主会话记录](GAMESESSION.md)。不以私有入口数量作为整游戏覆盖率，不把本专项命令称为自然回合、图形验收或1998官方游戏一致性证明。

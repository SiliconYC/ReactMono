# 原主屏移植

## 当前范围（2026-10-24，#148）

固定参考`tools/screens/main_screen.cpp`和`.hpp`，沿用[已验证的Frame/字体基础](NATIVE_UI.md)。代码为`main_screen.py`（时钟、输入、GO/骰子和顶层顺序）、`main_panels.py`（工具栏、信息/头部、地图/日历）、`main_text.py`（原主屏单色墨框锚定与色章）、`main_screen_types.py`（稳定编号与真实宿主回调）。四文件797物理行，不将行数或语法定义映射折算为功能完成率。

六项定向测试和本模块提交的完整Python388/388、Ruff通过。原辅助函数在Python类中被重复绑定实例的冒烟失败已补RED用例并修复；开发预设解析也通过先失败的Unicode数字/空格用例限制为原`atoi`的ASCII域。最终代码的完整原MainScreen画布/内部值/真实输入差分已通过，仍没有正式Pygame主游戏窗口。

## 保留的源行为

- 三视图、四页玩家信息、原工具栏命中编号和原图；金额、地产/连锁/设施数、股市值/成本与贷款天数读取真实世界。股票页的原`double`逐项转`int64`与核心x87财富算法分开保留。
- 主屏文字以单色字形墨框锚定，竖排间距和随字号增宽的描粗不同于通用菜单，不能复用菜单的测量位置。
- 显示玩家覆盖（包括槽0）会阻止GO/回合工具按钮出现；覆盖只影响画面，不修改规则当前玩家。
- 小地图/全图使用原定点比例、业主色章、原人物标记；旋转/拖拽/右键恢复跟随，日历/季节/节庆和月历休市色按源。
- GO轻点在释放时触发；移动曼哈顿距离大于6取消轻点并拖动。原骰数热点、边界、停留/龟行图与闪烁周期保留。
- 投掷姿态80毫秒/帧，骰子FLC28毫秒/帧，结果面停留500毫秒，原声音10在指定FLC帧触发。`api_骰子忙()`由应用用于暂停规则时钟；本组件没有自行结算规则。
- FLC解码失败时循环原Panel3骰面、缺少姿态时跳过投掷，都是固定参考明确存在的回退，未生成替代素材。

## 差分与未完成边界

`main_screen_oracle.cpp`直接编译固定MainScreen及原绘图代码，仅测试编译开放访问控制，参考源保持未改。`differential_main_screen.py`使用独立Python会话，逐条比较完整640×480 RGB555原字节、显示状态/骰子时钟/姿态、按钮区域/启用/声音标志、实际点击回调及声音请求。像素只经本地管道传输，不公开截图或商业文本。

场景来自原八图合法新局参数和两份外部原DAT；静态面板之外，输入时间线通过真实命中区域切页/旋转/地图拖拽/GO轻点或拖拽，真正调用Python公开掷骰/骰数/核心时钟。测试宿主对菜单按钮只记录“打开该功能”的请求，这是组件回调测试，不能视为已实现菜单。初版夹具误将工程车状态3当成合法新局交通，原C++拒绝；测试修为合法0/1/2，未放宽正式规则。

最终两组全部通过：基础2408输入/739737600像素，包含三视图/四页信息/两种日历、十二人物、真实原存档和特殊预设输入；补充1212输入/372326400像素，包含八方向/三种骰数、十二人物投掷姿态、全部36个FLC帧边界、500毫秒结果停留和声音触发。合计3620完整画布/1112064000像素，全部内部状态和回调也逐条一致，见[基础报告](evidence/main-screen-differential.json)及[旋转/逐帧报告](evidence/main-screen-rotations-differential.json)。报告有输入与四个实现文件哈希；最终哈希在发布前重新核对。首次两组通过后，ASCII预设修复又完整重跑，两组仍通过。

以上没有定向覆盖工程车交通3、受伤/梦游/水上的投掷路径或缺失FLC回退；保留为源码转写，不能折算为已验收。相同字体/FreeType的C++一致也不等于原1998年GDI字体完全一致。

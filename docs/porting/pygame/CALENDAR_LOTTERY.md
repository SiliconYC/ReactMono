# 节日与彩票

固定依据为 `src/holidays.cpp`、`src/lottery.cpp` 和对应头/测试；Python 对应 `holidays.py/holiday_tables.py/lottery.py`。只移植公开源码中的规则标量与素材编号，不包含商业图像、声音、影片或字体。

## 日期与表现接口

原农历采用285个运行段，覆盖公历1998-01-01至2020-12-31。首日农历为1997-12-03，因此 `api_农历` 返回未施加公历历元限制的 `(年, 月, 日)` 元组。超过表尾返回 `None`，不读相邻 EXE 字节，也不套用现代农历算法。

八图各24行节日规则，保留以下源行为：遇农历行后比较寄存值不恢复公历；第几周规则在目标星期早于月首星期时以 `7` 替代星期；`0x80` 行跳过，继续匹配后续行。表外只考虑固定公历节日和周日，周六并非默认休市日。

`api_节日行` 返回原行号，`api_节日图片` 返回 Data.mkf 图片编号。`api_庆祝` 返回原 FLC、音效和 MIDI 编号，零值代表缺项；本模块没有实际播放。贷款从当前日期加90天，再顺延休市日。

## 彩票与结算

可见号码1–36，保存所有者仍为玩家槽位加一。票价固定1000现金、不随物价变化，不计入累计支出；电脑必须严格拥有超过1000现金才购买。无可购票时不抽随机数，只有一个可购号时仍抽一次。

无人持票时不开票；任一玩家超过十张时，从全部已售号码升序表中抽取，否则从全部36号抽取。流奖同时保留票和公共基金，中奖现金及累计收入按原32位回绕，随后清空全部票与基金。破产退票不退费。`api_开奖日` 接受原存档 `(日, 月, 年)` 顺序，只判断每月15日。

## 自动证据

[报告](evidence/calendar-lottery-differential.json) 的96,456个日历用例包含1998–2030逐日八图，以及2100闰日和65535年边界；比较农历编码、节日行、图片、休市和庆祝索引，其中3168个月首用例另比较贷款到期日。结果均与固定 C++ 一致。

彩票在四图、三种种子共12组中执行5880个动作，逐步比较所有返回字段、异常类别、RNG与完整DAT；包括2722次异常拒绝，以及余额不足、售罄等正常拒绝返回。测试设置操作显式以 `t/p/f` 区别于模块入口，不属于正式游戏行为。没有把这些序列称为真实回合或长局。

局部测试覆盖历史表首尾、超表回退、周末、节日资源编号、贷款顺延、人工/电脑余额差异、流奖、十一票阈值、退票和32位回绕。本批新增八项，完整Python测试85/85、Ruff通过。以上是与 C++ 的对照，未独立执行原1998年EXE或证明实际节日动画播放。

# 原银行与一级股屏幕

## 代码与职责（2026-10-24，#150）

`bank_screen.py`573物理行与`primary_stock_screen.py`54行对应固定`tools/screens/finance.cpp`中的银行和认购提示。共用数字板见 [数字板](NUMBER_PAD.md)，规则核心见 [会话金融](GAMESESSION_FINANCE.md)。界面只绘制、采集数额、调用按选项值派发的真实核心回调；不改世界、重新结算、制造事件或使用C++后端。

- ATM保留Panel24、十位输入、存取切换、量尺34级、逐键按压和938号放大键盘入口。放大量板取消停在ATM；ATM直接输入0确认则按原离开。一次存取被接受才清零并离开，被拒绝保留输入并请求错误声。
- ATM结束后只要决策含3/4/5/6任一选项就转柜台，否则回答离开；柜台/董事室的取消、退出和交易后的离开顺序分开保留。
- 柜台保留两秒换行、眨眼/口形、滑入侧板、季节/节日、星期和贷款到期日。借款上限取真实财富减现贷，反馈两条完成对白；还款超过可用现金和存款时只按原重新询问一次。
- 董事室统计其它所有槽的存款并钳制有符号32位，保留融资本金与可用额度；成功融资/归还后先提交交易再提交离开。缺钱、零融资与拒绝不能冒充成功。
- 一级股保留Panel73:5提示、原公司名/股价/最多股数、数字板位置以及取消等同零股；公司名从外部PE的八图96名称地址读取。

长台词从外部`Speaking`编号75–91读取；89号保留参考银行改写变体，原文读取机制见 [消息](MESSAGES.md)。暂禁放款提示从外部PE地址`0x464ad5`读取并按参考高位屏蔽天数；公开代码只保存GPL参考中的短标签和格式拼接。素材、字体、原程序、商业长台词及像素均不上传。

## 参考边界与约束

`owns_bank`按源码仅检查当前节点属于公司且业主匹配，没有再次检查公司类型；不擅自改成其它判断。董事室归还按钮依原始终注册，核心仍可拒绝不合法回答。存款按钮也保留原界面门控，不能由UI推断核心必定接受。

台词每次`say`递增序号，再按当前行与已发声序号去重；绘制时才请求配音。输入板活跃时保留最后一行，2倍板另在顶部显示同一提示。回调宿主按原只保留画框/声音，下一帧再处理对白发声；不在动作回调里提前配音。损坏日期只省略星期/到期日，仍画季节及原数字。

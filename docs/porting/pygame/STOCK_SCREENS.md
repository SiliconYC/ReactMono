# 原股票界面

## 代码与规则分工（2026-10-24，#150）

固定`tools/screens/stocks.cpp`429物理行对应`stock_screen.py`229行、`stock_screen_draw.py`102行及`stock_info.py`203行。原Panel75报价/持仓/公司资讯、历史走势图和股权饼图均使用原素材与字体。八图96名称从外部PE读取，数额输入复用 [数字板](NUMBER_PAD.md)。实际买卖仍交给真实核心回调，屏幕不改持仓/资金/股价/历史，不消费随机数。

- 原休市、停牌、涨跌停、可购股数/持有股数门控；选择行后再次点同一行打开资讯。取消先关闭资讯，再由持仓页回报价页，最后离开。
- 买卖上限按当前报价和存款计算。用户取消或输入0不交易，核心拒绝时显示原1500毫秒提示；不能假设UI门控已保证核心接受。
- 红黑卡目标仍画报价页并禁用交易，第一次点选、第二次提交原选项编号；取消清选择。只读停留页不注册目标按钮。
- 价格精度以现价幅度15/150为界；涨跌差、百分比、历史均价和坐标按原binary32运算边界舍入。历史环从游标的非零位开始，否则从零走，遇原零位停止，最多144点。
- 公司楼图依八图×十二类型表，持仓页标记经营者；饼图依原取`header.current_player`的持股比例，与屏幕查询玩家参数分开。不能为方便改成查询者的持股。

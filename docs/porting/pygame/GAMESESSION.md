# 主会话移植增量

实施顺序见 [计划](GAMESESSION_PLAN.md)，固定来源`src/game.cpp`4176行及`include/rich4/game.hpp`。本文件持续区分会话内部组件与真正可玩主游戏。

## 数据、事务和表现分发

`game_types.py`建立原六阶段、二十一决策、十三事件/公告、三语句表、三十三效果编号，以及全部决策/转盘/小游戏/托管/事件/月报/移动/效果数据字段。数据模型并不等于已实现这些规则；月结/转盘等嵌套字段仍需后续真实触发验证。

`game_transactions.py`移植原`run_rule/drop_replayed`。仅保存源指定的世界、RNG、卡片电脑记忆、队列长度和旧阶段；不擅自把整个会话做快照。等待选择时回滚规则，保存已展示事件/效果与续执行闭包；回答后带答案重放，只扣一次款、抽一次规则随机。

表现去重要求旧序列完整匹配，部分匹配不删除，避免吞掉新事件。效果比较忽略相对事件位，删除事件后按严格小于关系修正交错位置。普通异常原样传播，保留源的部分变更，不捕获后伪装成功。不支持异常仅用于固定源确有的缺依赖分支，不可作为未移植规则的跳过入口。

`game_presentation.py`移植原事件/效果/服装/卡图/公告/语句与阶段结束逻辑。事件语音与卡/道具气泡的缺席过滤不同；金额和缺席语音的中间门槛仍会消费共享随机数，不能误当作纯绘制而移到另一个流。地产落点有八tick原停留。购地后神明/工程车分支已经按源接线，但需要后续完整会话提供真实回调，尚未作为完整结算验收。

## 剩余主会话

### 引用语义回归（2026-10-24）

C++的世界值赋保留`World`本身的地址，卡片电脑记忆赋值和破产状态重置也保留对象及嵌入数组的引用。Python原来重绑定对象，跨选择保留的模块参数会读到旧世界。[初次失败](evidence/game-identity-initial-failure.json)在回复后的DAT偏移44（现金）复现，不能由原有不保留引用的事务探针发现。

世界现在原位覆盖独立深拷贝的字段，破产状态逐字段重置并原位清空敌意，电脑记忆原位赋值。四项先失败的定向测试覆盖世界参数、真实时光机道具回调、状态/敌意和电脑记忆引用；[八图三种子144命令](evidence/game-identity-differential.json)直接比较原C++引用行为及完整状态。这里没有承诺世界内部动态容器元素引用在世界整体赋值后仍有效，原C++也没有这个保证。

最终修复代码重跑原18648命令，24组输入/逐步状态哈希和计数与原报告全部相同，见[回归清单](evidence/game-identity-regression.json)。

`game_motion.py`已转写原出场/老化/回合入口/AI/掷骰/移动和前瞻，十三项定向测试；`game_property.py`已转写地产/设施/公司、探望/救援、轮盘/彩票和收卡，十二项定向测试。真实会话依赖仍在接入，这两组尚未做完整会话差分，不能标为完整可玩回合。

`game_finance.py`的支付/破产/银行/贷款/融资/分红/月结/租约，十九项定向测试及八图三种子77455命令私有入口差分通过，含非空月报完整字段。具体规则、边界和未涵盖回调见[金融结算](GAMESESSION_FINANCE.md)。`game_actors.py`的真实收容/防御/建筑/物件/拍卖已通过81403命令原事务接线差分，见[角色与被动防御](GAMESESSION_ACTORS.md)。实例扫描与其余模块回调继续在`game_actions.py`接入。

## 公开主会话验证中

`game.py`按原构造及公开操作接通骰子、卡片、道具、股票、交易、决策回答、小游戏真实结果提交、托管及原DAT导出；`game_landing.py`接通事件/商店/魔法、落点/日期/特殊角色及月末。原DAT仅允许待命/终局保存，不包含RNG/阶段；不将其称为运行恢复。

首次自然差分发现38天时银行续行标志名称不一致，漏执行过路后的真实遭遇。修复前先补失败单测，保留[失败](evidence/game-session-initial-failure.json)。修复后同输入完整236天自然终局、9380命令通过，见[首条时间线](evidence/game-session-first-natural.json)。早先未对照的222天Python冒烟结果已被这次更强验证取代，不拿旧结果证明规则正确。

```sh
uv run --project pygame python pygame/tools/differential_game_session.py \
  --source /path/to/pinned-cpp --build /tmp/rich4-cpp-core \
  --assets /path/to/Rich4 --autopilot --maps 0 --seeds 1 \
  --days 366 --report /tmp/game-session-natural.json
```

这次直接调用原公开`GameSession`，从实际MKF新局开始，只发公开操作和时钟，没有手牌/资金/地产注入。每条输入比较完整世界DAT和四个历史DAT原字节、RNG、动画/剩余步/时钟、决策/目标位置、事件/效果/转盘/月报、托管/服装/持续记忆等值状态。仅测试进程编译固定源并关闭访问控制以读取内部值；正式Python执行不调用C++。人类位保留、启用原托管策略，另行扩展自动输入策略以覆盖人工控制玩家的公开决策；这不等于真人桌面试玩。

### 八图自然差分结果

[托管报告](evidence/game-session-autopilot-differential.json)包含八图三种子的24条时间线、356086条公开命令、7897游戏日。11场按真实规则终局，13场推进到366天目标；包含一场人类槽获胜，其余终局按原人类位/破产规则处理。没有强行指定赢家或截去首次不匹配状态，所有比较通过。

[人工控制玩家自动输入报告](evidence/game-session-human-differential.json)另有一条184天自然终局、12373命令，其中174次掷骰、67次真实决策回答，其余为时钟/清队列。它沿公开接口操作人类槽，验证选择/转盘等接线，但不是人在窗口里点击；未覆盖每个主动卡/道具/股票/交易公开入口及全部人物配置。

合计25条自然时间线368459命令、8081游戏日。观察器额外直接逐字节比较四个历史快照，不以哈希代替比较；报告里的SHA256用于后续识别同一输入/输出。记录了运行代码和测试适配器哈希，首条236天用最终代码复跑并核实原输入/状态哈希不变。共享观察器改造后的144命令引用回归也通过。

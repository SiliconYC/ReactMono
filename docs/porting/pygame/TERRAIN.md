# GND与定点地形扫描

固定来源 `src/terrain.cpp`、`include/rich4/terrain.hpp`，Python 对应 `terrain.py`。GND格式与转换来自公开GPL源码中的 mytbk/rich4 研究；本模块不带原商业纹理。外部 `map.mkf` 偶数条目为八图GND，奇数条目为已验证的世界元数据。

## 接口与整数契约

`地面_类.api_解码` 验证16字节头、256个小端调色值、宽高索引数量、纹理数量与索引边界。保留头的保留值，瓦片为32×32个索引字节。`api_总览` 按索引铺出俯视纹理图，默认限制16M像素；这不是游戏相机。

`地形_类.api_绘瓦片` 接收RGB555目标、1024字节纹理、256色调色板、四个 `(y,x)` 点和 `(左,顶,右,底)` 裁剪框。沿用原有符号16位角点、16.16定点、32位回绕及向零截断除法；负斜率的纹理低16位以 `0xFFFF` 起步。纹理左右侧按边的原垂直方向赋值，即使该边改变另一侧X界限也不调整规则。

扫描在首个未触及行终止，右边/下边为半开界限。调色板索引0仍是完全不透明地面，不沿用SPR的透明索引规则。有目标掩码时仅画到的像素置1；没有掩码时不额外生成。空框和退化边可不绘制，超出原有符号边高域则拒绝。

## 自动证据与范围

[报告](evidence/terrain-differential.json) 逐字节比较八张真实GND的全部解析调色板、索引、纹理及总览，共42,467,328个总览像素。另4010组四边形（其中4组边高拒绝）比较状态、完整64×48像素与可选掩码，涵盖不同绕向、非凸角序、负坐标、空/越界裁剪和极值。初轮总览通过后，自审补齐全部解析字段直接比较并全量重跑，通过。

九项局部测试，完整Python108/108、Ruff通过。数据、商业解码图与扫描输出仅写临时目录，公开报告只留数值和哈希。尚未实现相机投影、道路/建筑/人物合成，也未验证地图帧率或图形操作；本批不能称八图游戏画面完成。

# Issue #5｜电脑玩家与可重复整局模拟

## 新能力
- 真人自行掷骰、买地或放弃、结束回合；进入电脑轮次后，电脑自动调用相同的合法规则命令，购买后保留至少 200 游戏币。
- 电脑不修改现金、产权或骰子；可配置现金保留阈值。重开游戏后，旧对局的待执行定时操作不会干扰新局。
- 无界面模拟以固定种子运行真人测试策略与电脑策略，记录每步操作及最终状态，检查现金、位置和产权不变量，并限制最大步骤。

## 实际核验（2026-10-15）
- `npm test`：28/28 自动测试通过；TypeScript 编译及静态页面构建通过。
- 0–99 共 100 种种子完整对局：最多 120 玩家轮次、276 条动作；破产终局 41 局，回合上限终局 59 局。所有对局均有终局事件、无拒绝的命令、无非法余额或产权；相同种子和策略轨迹一致。
- 构造场景分别覆盖 200 游戏币买入边界、余额不足放弃、回合上限、破产、非法输入。
- Chromium 使用本地 React UMD 兼容资源及内联静态模块验证真实按钮流程：真人完成一次购地与回合后，电脑自动完成投骰、购地和回合，操作权回到第 2 轮真人，浏览器脚本错误为 0。
- **限制**：沙盒的浏览器阻断本地 HTTP 和公网网络，未能直接访问发布网址验证 React 18 CDN 加载。平台 Pages 部署成功**不等于**公网浏览器已测。PWA/离线存档属于 P2。

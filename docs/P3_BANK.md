# P3-07 银行存取款及逐轮利息（Issue #36）

- 纯静态本机虚拟银行，**没有真实账户、在线接口或服务器**；创建新局时开启 `bankEnabled:true`。默认逐轮利率为 **100 基点＝1%**，可用 `bankInterestBps` 配置 0～1000 基点。
- 只有轮到该玩家且处于 `await_end_turn` 时允许正整数存/取款；余额、现金都必须为非负安全整数，上限一万亿游戏币；错误操作返回拒绝，不修改状态。
- 现金与存款之间转移总资产守恒，`netWorth` 包含银行余额。存款**不能直接购买地产**；遇到租金债务时**先以现金偿还、再自动取足银行余额、最后执行 #35 的地产变现救济**；无资产则破产。
- 每个**完整新轮次**开始时，对存款按 `floor(balance×interestBps/10000)` 结息。银行快照记录 `lastInterestRound`，与游戏 `round` 必须一致；不得跳轮/重复结息。与 #38 虚构股票及掷骰随机数独立。
- 旧 v1/v2/v3 存档迁移显式存款余额 0，旧 v4 存档与默认纯逻辑 P2 引擎保持银行功能关闭，避免改变历史差分回放；最新新局及银行存档使用原有带校验 JSON 与 IndexedDB/PWA。

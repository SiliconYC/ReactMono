# 2026-10-19 数据驱动压力地图验收

来源：[P007](../proposals/P007-scalable-world-maps.md)、[Issue #94](https://github.com/SiliconYC/ReactMono/issues/94)。集成目标为本地 `dev`；不修改 `main`，不发布正式服务。

## 交付结果

- 背景艺术选择连续地表＋局部分区景观，比较了扩大圆岛、整体异形岛与分块世界三种路径；只交设计，没有修改背景渲染。
- 五张可选关卡与内部 16 格 demo 全部由 JSON 定义。新增曲湾长街 60 格、双湾漫游 120 格、群峰回廊 360 格；三图形状不同，有实际凹段。数据源、三个独立交换容器、轮廓蓝图、通用生成器与 CLI 校验齐全。
- 通用选图读取名称、格数、真实路线缩略图及默认轮数。地块经济、事件、卡站、特殊设施均可由 JSON 配置；无地图 ID 专属形状函数或注册分支。
- 保留原地图几何、经济及存档格式。原 16 格 demo 的完整 `DEMO_CONFIG` 与迁移前从实际模块导出的对象逐字段比较一致。

## 独立审查与修复

只读审查按 requesting-code-review 技能由独立代理执行，未修改工作树；首次结论为有修复后可合并。两项重要发现分别是目录名称/卡片上限与存档不一致，以及设施位置不能用数据搬迁。两项均以失败测试复现后修复，定向 7/7 与全量 162/162 通过。默认轮数被 UI 覆盖也已修正，浏览器把输入先改为 7 再选图，验证关卡默认值确实被应用。

压力模拟另外揭露基础无风格行动器在到访限制下非法请求升级的问题；修复时复用已有 `propertyVisitAvailable`，并排除已抵押地产。旧风格与规则回归保留，没有删除或放宽核心测试。

## 边界、风险与回滚

真实画面见 [地图说明](README.md#背景已知问题)。大图仍有圆岛承载不足、固定海面、远景雾/裁切与地产锚点重叠问题，按所有者要求留待后续背景/布局实施。本轮未证明真机手机 GPU、长期性能、数百格经济平衡或真人趣味性，未关闭 #73 或标记 P4 完成。

当前关卡格式仍是最多 512 格的正交单闭环；新地表设计的可扩展性不等于引擎已经支持任意分叉或无限地图。当前不提供游戏内外部关卡导入，也不启用服务器、账号、云同步或新运行时依赖。

回滚本轮实现提交可恢复原程序；旧档无需迁移。新地图存档在旧版本中不能加载，应保留 JSON 导出并回到含对应注册定义的版本继续。没有为了回滚或验收清除已有存档。

本轮集成本地 `dev` 供所有者验证。远程 PR、CI 与 Pages 状态单独说明；本地测试不冒充远程通过。耗时/Token 成本未取得可靠统计，不补造。

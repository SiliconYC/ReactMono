# P008：关卡场景成为一等数据

2026-10-20，所有者要求立即实施。P007 的连续地表与清晰镜头保留，背景生成方向由本提案取代。

## 问题与选择

P007 通过地形延展和散布植被解决承载问题，但缺乏关卡构图；规则网格直接成为道路形状，路线僵硬。关卡数量少，采用精心编排的显式场景，而非运行时生成。

每个 JSON 关卡新增 `world`：版本、基础地表/背景颜色、具有明确顶点与洞的地形面、逐格道路与地产坐标、逐个具名景物及位置/朝向/尺度。运行时不得根据种子、道路或区块创造植被/景观；只允许根据数据构建几何、实例化、裁切。无场景的旧格式可作为规则草稿读取，正式内置关卡必须具备场景。世界数据不写入对局，存档继续使用原地图标识、格号、路线与规则坐标。

## 关卡美术

五个可玩场景分别设计为湖畔花园、海港半岛、河湾小镇、双湖城与山麓长途。道路使用精心编排的曲线节点，地产有独立位置，地形与景物共同形成中心、街区与留白；不再将规则格子的行列当成最终外形。每株树、花圃、石头、路灯、长椅、码头和地标均有稳定的显式记录。曲线与几何可由离线绘图工具转成坐标，最终运行数据无可执行配方。

## 验收

- 所有内置关卡有完整世界数据；缺失坐标、非有限值、自交面、重复景物 ID、未知种类与悬空引用被拒绝。
- 道路/地产无相互侵占；背景不会随缩放、平移或访问顺序改变位置/数量。
- 20/24/60/120/360 格地图有不同且可辨识的构图，预览、迷你地图、棋子、道路、地块点击使用相同数据。
- 大图保留清晰的跟随/浏览/全景，桌面和手机能完成真实掷骰/买地，旧档可读；统一光照阴影。
- Node、构建与真实浏览器验证，截图人工查看；记录性能、遗留不足。

回滚：回退本任务提交；未修改规则/存档结构，已有对局不丢失。

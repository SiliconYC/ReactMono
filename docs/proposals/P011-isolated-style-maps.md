# P011：以独立小地图探索视觉风格

## 来源与目标

2026-10-22，所有者认可晴湾花园搭建小城镇的尝试，同时明确当前重点是探索风格，而非扩充内容量。参考图为广告海报：采用青柠草地、奶油色圆角踏石、柔软阴影、蓝色屋顶和玩具树。只研究地块、背景与装饰，不复制广告控件、红包或照片。

用户底线：不得改变其他关卡设计，不得破坏整个网站设计。每个探索关卡是独立空间。

## 最小切片与方案比较

首轮只创建「青柠游园」`lime-garden-30`，30 格闭环，可使用既有规则、设施、经济、电脑与存档。

- 复用所有旧模型而仅更换颜色：改动少，但很难探索不同的形体和材质，未选用。
- 为新图建立独立的地表、踏石和景物组件：允许改变形体，同时将入口限制在新地图标识，选用。
- 修改共享美术和网站主题：会突破所有者约束，不进入实施范围。

地表使用连续草地纹理；踏石具有圆角轮廓、薄厚度、金币或站点符号；蓝瓷圆亭、牌坊、圆冠树、花朵和长椅作为主要装饰。购地显示玩家颜色，建设后出现奶油墙小屋；空地只用微小的草芽标识，避免出现大片待售平台。

## 边界与准入

已查重开放任务，仅 `#73` 是正式版综合验收。用户明确指定的最小切片具有独立数据容器、独立表现入口、可重现模拟与浏览器验收方式，因此晋升 [Issue #131](https://github.com/SiliconYC/ReactMono/issues/131)。

- 原六个关卡容器与基线 `49880a7` 全量相等。
- 不改全站样式、页面流程、规则、存档格式、共享灯光或阴影策略。
- 新图通过地块与地产空间约束；实际支持开局、购地、建设和完整结算。
- 桌面及手机浏览器视口留存真实截图；数值测试不能判定风格已最终确定。

## 结果与剩余问题

实现与验收见[青柠游园记录](../maps/lime-garden/acceptance.md)。本次只交付一种可实际游玩的风格试验，不自动创建更多地图，不宣称已确定产品最终风格；真人偏好、物理手机表现和长局经济平衡仍需后续证据。

回滚独立实现提交可撤销入口和新图。若已有新图存档，撤销地图注册后无法读取这些存档，应先导出备份或保留不可选的旧地图定义。

## 2026-10-22：所有者反馈后的造型修订

所有者认为首轮单椭球树冠、稀疏圆亭屋面和近似的两级房屋过于简陋，且缺少建设动画。首轮规则与浏览器通过不代表视觉获得认可。明确范围晋升 [#132](https://github.com/SiliconYC/ReactMono/issues/132)，仍只修改青柠游园专用美术：分叉与多簇树冠、实际密排瓦垄、独立的一层庭院/两层阳台住宅及短暂升起落定动画。旧关卡容器不变，建设动画不改变规则或存档。

实现与真实验收见[造型修订记录](../maps/lime-garden/refinement-2026-10-22.md)。全地图调试工具属于独立的 [P012](P012-local-debug-tools.md)，不将工具范围混入美术隔离边界。

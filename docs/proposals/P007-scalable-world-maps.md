# P007：可扩展地表艺术与数据驱动压力地图

2026-10-19，来源：所有者明确要求。目标分支 `dev`；本轮不修改背景渲染，不发布正式服务。

## 证据与准入

`MiniatureTown.tsx` 用随包围盒放大的圆柱承载棋盘，海面仍固定半径 22；圆形轮廓无法表达凹形、狭长和多区域地图。`maps.ts` 用代码生成环形地图，`config.ts` 用代码生成地产；`app.tsx` 的选图和开局写死两张地图。现有 #73 是综合验收，#92 是界面重做，无同类开放实施 Issue。

价值：在不提前重做背景的条件下，以 60/120/360 格实际关卡暴露尺寸、形状和加载假设，为后续地表工作提供可重复输入。范围、验证与回滚清晰，数据基础设施晋升实施；背景渲染继续研究。

## 背景艺术方案：连续地表与局部分区景观

推荐保留明亮、低多边形、微缩街区风格，把“游戏在一座岛上”改为“路线穿行于连续世界”。基础色是柔和草地、砂砾或街区地坪；道路和地产是视觉焦点，远处用低对比植被、城市剪影与大气层次收束。海只在关卡要求的海岸区域出现。

比较：①按包围盒放大圆岛，开发便宜，但凹区、超长地图仍浪费面积，且形状假设未消除，否决。②整张路线外扩后做单块异形岛，可适配部分轮廓，但三角化、孔洞和远景成本随全图增长，留作有明确岛屿主题的选项。③连续地表分块、局部景观独立描述，没有整体外边界和固定海面约束，推荐。

### 美术层级

1. **连续基底**：全局统一地表高度；用无缝、世界坐标稳定的色块/细纹理构成平地。实现时仅生成视锥及缓冲区域内的地表块，远景逐渐融入背景色；不绘制随相机移动可见的台座边缘。
2. **路线与地产**：由关卡格点和巡回顺序形成道路，地产有独立局部锚点与朝向，不能再按包围盒边缘推断“外侧”。转角、凹口、近邻道路需要占用检测；路面、薄板、地基共用高度基准，避免重叠闪烁。
3. **区域景观**：未来的地形数据独立描述多边形区域及孔洞，例如草地、城区、河流、海岸和桥梁；路线不是海岸线。空旷区域可留白，装饰密度由区域种子决定，与骰子随机数分离。显式地标优先于自动装饰，并有道路/地产禁入区。
4. **远景**：低对比植被或建筑轮廓、同色系雾化。概览看完整路线和区域色带，跟随镜头看街角细节；缩放改变细节级别，不改变道路身份。

### 任意形状与规模的契约

地表无全图固定半径、固定宽高或强制凸轮廓；凹形、长条、带孔洞、多片区域均按空间分块独立处理。路线拓扑、坐标布局、地形和装饰是不同数据层，未来支持分叉时另行升级路线格式，不能把当前单一巡回路线冒称为任意图拓扑。理论上地表方案不要求地图尺寸上限；实际设备仍有显存、绘制与数值精度预算，超大世界需视锥剔除、实例化、分块与相机相对坐标，不能承诺无限性能。

全场景继续统一投影/受影策略。未来阴影以可见区域配置光源与阴影相机，按共同原因处理接缝/重叠，不关闭某类物体阴影。本轮不调整阴影、雾、镜头或台座，压力图上的画面缺陷是后续实施输入。

### 后续渲染验收门槛

同一组 20/24/60/120/360 格地图覆盖：概览/跟随、首尾接缝、凹角、狭长区域、地图边缘、手机与桌面；道路和地产有可辨认落点，无悬空、地表边界、装饰侵占、闪烁及局部阴影例外。测量空闲/移动帧时间、draw calls、显存/几何数量并保存设备信息；先记录当前基线再决定性能门槛。本轮仅设计，不把这些门槛登记为已通过。

## 本轮数据基础设施规格

- `src/data/levels.json` 是唯一内置关卡目录，每个条目是完整可交换的数据容器：展示名/说明、版本化地图坐标与 route、地块经济数据、事件/卡片站与开局默认值；不含可执行表达式。
- 把原有 24/20 格地图及内部 16 格测试地图迁入同一格式，原坐标、路线、名称、价格、默认行为及旧存档保持兼容。内部 16 格不加入正式选图。
- 增加三张有凹口的非矩形闭合路线：曲湾 60、双湾 120、群峰 360。相邻格与首尾为曼哈顿距离 1，无重复坐标；三图使用不同轮廓，不是把方环放大。
- 通用加载器校验目录、ID/版本、有限整数范围、唯一格点、连续闭环、route 排列、地块/站点引用和经济值；内置目录递归冻结，游戏状态复制隔离。新地图只需编辑 JSON，无需增加 TypeScript 分支。
- 存档保留既有 GameMap 格式和注册地图精确比对，拒绝伪造地图；历史 custom-N 推断继续兼容。已发布地图 ID/version 的几何不可原地修改，未来修改需新 ID 并保留旧条目。
- 通用选图卡使用真实路线缩略图、名称、格数与说明；真实开局、读写档和规则模拟使用同一数据。
- 提供 `npm run maps:validate -- [文件]`，校验任意同格式目录并报告每张图的尺寸；新目录需并入内置 JSON 才进入离线游戏，不增加运行时远端依赖或地图编辑器。

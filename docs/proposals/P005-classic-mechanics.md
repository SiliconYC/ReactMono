# P005｜致敬《大富翁4》：哪些玩法必需，哪些可重设计？

- **主题**：游戏设计
- **来源**：原拟发布的 Discussion D05
- **阶段**：P1–P4（长期研究）
- **状态**：P1 核心机制已进入 P002 的五项任务，其余复杂玩法继续研究/延期；不自动生成全套玩法 Issue
- **归属**：[候选池](../EVOLUTION_POOL.md)

## 目标

重现经典《大富翁4》引人入胜的轮流移动、地产竞争、经济决策、卡片策略和偶发事件等体验；不能用纯粹堆机制代替“好玩”，也不能因为追求像素级还原使首个可玩版本迟迟无法完成。

原作的人物形象、地图、美术、配乐、音效、台词等需使用原创或明确取得授权的替代素材；不暗示与原著作权人有授权关系。

## 值得研究的核心机制

- 地图与交通工具、骰子及回合流转。
- 土地购置、地产升级、过路费、不同建筑的经营特色。
- 股票与银行等不同风险和收益来源。
- 卡片、道具、特殊地块、随机事件和特殊状态。
- 玩家之间的竞争策略、电脑对手的行为差异、游戏节奏和胜负条件。

以上只是**候选范围**。不能因为列表写了某个机制就立刻建立 Issue；优先问“对玩家体验的重要性、当前阶段的价值和可验证程度”。

## 需要比较的路线

1. **忠实复制规则**：识别度高，但可能继承旧式操作与节奏问题。
2. **保留核心、简化旧机制**：加快完成和测试，但可能失去部分原版魅力。
3. **原创扩展玩法**：潜力大，却容易稀释复刻目标或造成范围失控。

建议以保留核心体验为基线，按当前阶段小步验证，不事先宣布所有扩展都是必要功能。

## 待研究的问题

- 哪些机制是玩家一眼能认出的“必需品”？哪些是可以延后的锦上添花？
- 哪些规则值得为了易玩、流畅和节奏而重新设计？
- 如何让 P1 的简单核心可扩展，同时避免过度设计？
- 如何通过实际对局、随机种子模拟及玩家体验反馈判断“更有趣”，而不是主观自夸？

## 首轮取舍（2026-10-15）

只采用 P1 必需的棋盘、投骰、地产交易、租金、破产和胜负。这些已经由 P002 归集为 #2–#6，不重复创建同名 Issue。复杂卡片、股票、土地升级、多人模式、精细音画等继续作为候选研究，实际 P2/P3/P4 阶段再按价值和验收标准选择。

## 晋升门槛

只有明确的当前玩家问题、至少一种候选方案、可验收标准和合理实施边界才晋升 Issue。长期争议保留在本提案并引用后续证据；否决的方案也记录原因。

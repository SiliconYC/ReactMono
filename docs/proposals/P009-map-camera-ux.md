# P009：地图鼠标操作与旋转可读性

2026-10-20，所有者定向授权。对现有地图交互做有限升级，不修改关卡、规则或存档。

## 设计

- 左键拖动平移，`Shift`＋左键或中键拖动旋转；滚轮缩放，保留触屏平移和双指缩放。旋转围绕当前观察点，俯仰限制在30至70度，防止钻入地面。
- 平移、方向键、小地图视域、全图取景、光照范围使用实际相机朝向。旋转本身不改变缩放；支持一键回正和 `R` 快捷键。
- 路砖编号有助于识别地产、卡片目标和小地图位置，因此保留。数字随相机方位保持正向，俯仰变化补偿字面压缩；远景仍自动隐藏，提供编号开关。
- 画布右键提供游戏内菜单：命中地块时显示地名、产权和价格等摘要，可查看详情或移到此地；公共操作为定位当前玩家、查看全图、视角回正、编号开关。仅接管地图画布，普通输入区域保留浏览器行为。
- 菜单支持屏幕边缘避让、外点/`Escape`关闭、键盘导航；操作提示说明鼠标映射。购买与升级继续由既有回合面板处理。

## 验收与风险

纯函数验证任意角度下的平移逆投影、俯仰限幅、数字朝向及足迹、全图投影边界。真实浏览器验证两种旋转手势不缩放、普通平移和滚轮、右键地块识别、菜单可达/键盘/边界、回正、减少动态、手机旧手势和大图。检查显式景物可见性与统一阴影、满建资源稳定性。完成后集成 `dev`；回滚本任务即可，存档不变。

## 实施结果

晋升 [#120](https://github.com/SiliconYC/ReactMono/issues/120)。已实现两种旋转、随视角的平移与全图适配、地面数字朝向补偿、地图右键菜单及回正。186项测试、五图十组回归、新交互真实浏览器与满建资源检查通过，独立审查问题已修复并复核。完整证据与边界见[地图操作验收](../maps/CAMERA_UX_ACCEPTANCE.md)；集成目标 `dev`，不发布正式服务。

## 2026-10-22：稳定镜头与系统交互修整

所有者在青柠游园实际体验中发现落地/购地跳切、俯仰受限、查询常驻和控件堆叠等问题，晋升 [#137](https://github.com/SiliconYC/ReactMono/issues/137)。本轮授权将共享相机、输入和回合修正用于全部关卡；青柠专用建筑另在 [P011](P011-isolated-style-maps.md) 留档，不改变其他地图数据或存档格式。

取消演出强制跟随和操作栏高度驱动的重新取景，俯仰改为 `12°–82°`；地块/角色按住查询、松手关闭，中键旋转与滚轮缩放分离，工具栏默认收拢。人物按道路初始化朝向；真实演出结束后自动继续，经营和交互期间暂停。命名统一为《大富翁 2026》。设计、真实双视口连续帧与原验收迁移边界见[交互修整验收](../interaction-polish/acceptance.md)；`295/295` 自动测试及相关完整浏览器检查通过，物理手机、长期真人体验和 `#73` 仍未完成。

所有者后续指出四秒资产窗口仍造成多余操作，并撤销中键管理，晋升 [#138](https://github.com/SiliconYC/ReactMono/issues/138)。现改为掷骰前经营，掷骰后仅为落点决策停顿，演出完成立即交接；中键交还浏览器，旋转保留 `Shift＋左键`。完整规则兼容和真实验收见[后续修正](../interaction-polish/landing-and-ownership.md)，不将上一轮测试通过作为产品流程正确的证明。

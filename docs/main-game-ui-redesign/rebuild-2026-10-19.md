## 采用的设计

保留规则、AI、IndexedDB/PWA 与可用的骰子 nonce/到达回调。重新组织 React 页面和 CSS，主程序不再加载旧二维布局覆盖链；旧美术样例和离线资源继续兼容。

- 标题：原创矢量微缩街区插画，清楚的标题和菜单；继续游戏优先，存档管理与设置完整可达。
- 准备：两地图卡、直接可见的 2～4 席姓名/类型/策略，固定底部开始；只有规则/种子/速度为更多设置。
- 对局：紧凑玩家卡、顶部轮次与镜头/菜单、底部墨绿行动条。购地明确费用/租金/余额，自有地建设直接出现。手牌与金融独立入口。
- 浮层：单个模态窗口负责资产、银行、股票、抵押、手牌、地块、事件、存档、设置、帮助。原生 dialog 处理背景 inert/焦点，Esc/遮罩关闭并恢复焦点。弹窗暂停 AI；演出未完只准查看。
- 世界：默认全景，跟随偏好独立持久化；用 HUD 实际边界拟合相机安全区。结果揭示在到达之后，租金/结局顺序阻挡下一输入。旧档没有到访限制时仍允许既有升级。

## 实际结果与证据

- 首轮失败：修改前主按钮只有浏览器默认高度；新增检查先失败，重做后通过。双击投骰误点新出现的跳过按钮、模态切换焦点丢失、终局落地路径 actorId 丢失、电脑夹在两名真人间时漏交接，均留下复现/失败记录并修复。普通购地和金融操作不重掷。
- 页面：主程序只加载 `game-ui.css`，不再叠加旧二维侧栏、3D覆盖层与浅色补丁。标题使用本仓库原创矢量插画；新局席位直接可见；行动条只承担当前阶段，交易/资产/手牌/存档/设置/帮助进入一个原生模态。
- 镜头：默认全景，跟随为独立持久偏好；根据真实 HUD 的 ResizeObserver 测量计算安全区。短横屏改为侧面行动卡，四人长姓名/大额现金采用可查精确值的摘要，资产页保留完整数字。
- 音画：先投骰、走路，后到访结果、租金、破产和胜利；音效同序。读取旧档静态恢复，跳过/正常/快速不改变规则结果。

# P3-06：地产出售、债务救济与破产清算（Issue #35）

## 规则契约

- 人工「出售地产」只允许地产所有者在 `await_end_turn` 执行，需确认；售价为 **地价×75% 向下取整，加已支付升级费×50% 向下取整**。出售后归无主、等级归零；`netWorth` 随实际售价变化，不能重复出售。
- 新游戏通过 `GameConfig.automaticLiquidation:true` 启用自动租金救济。交不起租金时按地产编号升序，将欠租人拥有的地产逐一按同一售价变现，直至足额或地产卖完；出租人只能收到本次实际支付额，最终若仍不足才破产。不会凭空生成负余额或重复支付租金。
- 出售与救济事件 `property_sold` / `property_liquidated` 都经过单一 `applyAction` 状态机，进入有校验和的 JSON 存档；无网络、无金融实物交易。公开游戏 UI 新建对局默认启用，玩家能在结束回合前查看价格并出售地产。
- **旧游戏及旧存档保留未启用状态**：原两人 `DEFAULT_CONFIG` 及既有 v1～v4 存档不自动救济，P2 的百种子逐操作差分测试保持原样，不以新功能覆盖旧回放语义。已存在的 v4 存档可以正常续局，新建立的救济版本另带校验过的可选布尔标记。

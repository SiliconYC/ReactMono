# 美术与前端重建方案

日期：2026-10-17。审查基线：`dev@a56058950966b1e4f3d56dec75caa250f1fcd0a3`。来源：[P006](../proposals/P006-3d-art-renewal.md)。

## 决策

**首选真 3D、低多边形微缩街区、固定斜俯视正交镜头。** React 负责界面与应用，Three.js / React Three Fiber 负责街区、角色和演出；规则仍是与渲染无关的离散棋盘系统。

借鉴 Crossy Road 的几何简洁、清晰轮廓、统一光照和模块复用，但人物要有性格、城市要有生活感，不能把正式美术标准降成若干彩色方块。对《大富翁4》的致敬落在沿街移动、买地成长、收租冲突、卡片干预与角色反应上，采用原创角色、建筑和声音。

**保留规则与存档底座；重建游戏表现层；有步骤地替换旧主界面和打包方式。** 不因已有代码就保留整页表单式游戏布局，也不因画面粗糙就重写已经可验证的经济系统。

## 本轮是什么状态

- 已完成：现状代码审查、当前版本本地浏览器开局/掷骰审查、现有 119 项 Node 测试，以及本目录的设计决策。
- 本轮没有实施 3D 游戏、生产模型或验证新的帧率目标。以下预算、时长与玩家体验指标是提议的验收目标，不是已取得的结果。
- 这是对用户本次请求的首选建议，不冒充所有者已经批准了新的发行预算或正式版验收标准。
- GitHub 当时仅有 [#73：P4 正式版综合验收](https://github.com/SiliconYC/ReactMono/issues/73) 开放，没有开放 PR。现有 P4 功能的完成不能替代正式游戏体验验收；本方案不关闭 #73，不宣称进入 P5。

## 下一步的投资顺序

先做一个**能够从开局玩到结束的 3D 纵向切片**：经典 24 格地图、两名角色、真实骰子与逐格行走、购买/升级/收租、电脑回合、存档与离线。先把其中一段街景、角色和完整回合打磨到可评判的质量，再按相同规格铺满地图。这个切片通过后，才扩充四角色、第二地图和全部事件演出。

首轮投入集中在一名完成度足够高的角色、一套有三个产权等级的建筑、一个完整回合的演出和正确的手机交互上。不要先量产十六方向素材、几十个角色、海量道具，或用不接规则的展示场景代替切片。

暂按桌面/平板横屏提供最完整的街区视野，手机竖屏仍可完成全部玩法。没有强制横屏、外部账号、联网资源或新增付费服务的前提。

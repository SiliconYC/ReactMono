# 全地图调试工具实施计划

> 执行技能：`superpowers:executing-plans`；所有者已授权实施，按仓库约定自主完成验收和集成。

**目标**：游戏菜单增加调试弹窗，逐玩家设置现金，从当前对局一键批量模拟指定整轮数，然后一次性更新画面。

**设计**：纯规则辅助函数复用现有策略和 `applyAction`，不重开对局、不换随机种子、不改变玩家真人/电脑身份。界面逐玩家输入非负整数现金；批量模拟按轮次增量推进，提前终局就停止。大量计算在本地 Web Worker 中执行，暂停常规电脑驱动，成功后清除过时演出并原子替换当前状态；失败不留下半更新局面。无后端，不逐帧播放模拟。

**技术**：TypeScript、React、Vite Web Worker；兼容既有存档、菜单与静态/PWA 构建。

## 文件与接口边界

- 新增 `src/core/debug-tools.ts`：现金调整与从既有状态继续模拟的纯函数；输入/输出均为实际 `GameState`。
- 新增 `src/ui/debug-simulation.worker.ts` 与专用弹窗组件及作用域样式：输入现金、轮数和运行反馈。
- `src/ui/app.tsx`：菜单入口、暂停并发动作、接收最终结果与清理旧演出。
- 新增 Node 与真实浏览器验收：覆盖所有注册地图，现金、局面推进和存档保持一致。

## 实施顺序

- [x] 先写并运行失败测试：每个玩家现金设置；非法输入不改局面；从中途阶段推进N轮；提前终局；随机状态、产权、玩家类型与存档合法。
- [x] 实现纯规则工具，复用真实策略动作，设置合理动作上限并明确失败原因。

- [x] 接入菜单并在运行期间冻结旧状态；模拟成功一次性更新场景，失败保留旧状态。
- [x] 桌面与手机真实操作验证：各地图调试入口、逐人现金、指定轮数、提前终局、错误输入、关闭窗口后正常继续游戏和存档。
- [x] 独立审查，运行全量测试与两套构建，集成 `dev`，不自动发布。

## 重点审查

- 真人交接、设施停留、待购地、待建设、商店、终局与破产玩家不会使模拟卡死。
- Worker 回包不能覆盖已切换/读取的另一个对局；组件卸载及时终止 Worker。
- 一键推进不会播出历史骰子、移动、租金或建造动画。
- 不放宽存档验证，不伪造规则动作，不改变既有核心测试。

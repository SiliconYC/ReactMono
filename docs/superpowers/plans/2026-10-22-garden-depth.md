# 青柠游园造型与建造动画实施计划

> 执行技能：`superpowers:executing-plans`；所有者已授权实施，按仓库约定自主完成验收和集成。

**目标**：仅深化青柠游园的树、圆亭和住宅，并给真实建设增加简短动画。

**设计**：分叉树干搭配多簇有层次树冠；圆亭使用有密排瓦垄与檐口层次的实际屋面几何；一级为单层庭院小屋，二级为带阳台的两层住宅。建造动画只响应当前对局的实际产权/等级变化，读档与批量模拟结果直接显示最终建筑，不重播历史。

**技术**：React、Three.js、R3F；继续场景统一阴影、贴地高度和批次复用，不引入外部素材或依赖。

## 任务与接口

- `src/demo3d/world/lime-garden-models.ts`：纯几何/模型构成参数及动画时间函数，供模型与独立测试读取。
- `src/demo3d/world/LimeGarden.tsx`：地面与路线保持，接入专用树、圆亭和住宅组件。
- 专用住宅组件：接收 `game`、`world`、`reducedMotion`；使用地块ID保留点击归属。
- `WorldCanvas.tsx`：向新图传递既有减少动态标记，不改变其他地图。

## 实施顺序

- [x] 实现多簇树、密瓦圆亭和两种不同住宅轮廓，所有模型范围保持在现有占用范围内。
- [x] 接入仅真实新建/升级触发的短动画；减少动态、挂载、读档、批量模拟无历史动画。
- [x] 实拍新局、一级/二级住宅、建造中/结束；检查旋转和阴影，运行全量测试与构建。
- [x] 独立审查，修正后集成 `dev`，保留本地服务。

## 重点审查

- 房体、树根和平台底部贴地，无挑选物体关闭阴影。
- 一级、二级住宅在正常游戏视角下轮廓和楼层数明显不同。
- 动画锚点固定地面；旋转不误选；读档和调试模拟不触发数百个建设动画。
- 旧六个地图容器及旧地图美术不变。

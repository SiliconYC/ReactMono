# P007 连续世界与大地图显示实施计划

> **For agentic workers:** 使用 superpowers:executing-plans 在当前会话逐项实现，结束时独立审查整条分支。所有者已授权设计、实现、验证、提交并合入本地 `dev`。

**Goal:** 20–360 格及不规则轮廓地图具有连续地表、无道路侵占的地产、清晰的全景与局部浏览。

**Architecture:** 延续 P007 推荐的连续世界，把空间布局、可见范围与画质策略提取为纯函数。地表只覆盖相机视域及缓冲，装饰采用稳定世界种子和占用检测；路线实例化、近景细节分级。正交镜头提供全景、跟随、缩放、拖动和路线小地图定位，雾/裁切/统一阴影随可见范围配置。

**Tech Stack:** 现有 React 18、R3F 8、Three.js 0.186.1、TypeScript、Node test、Playwright；不加依赖。

**Spec:** `docs/proposals/P007-scalable-world-maps.md` 背景艺术方案及所有者本轮显示清晰度要求。

## Global Constraints

- 仅静态/PWA、简体中文；不改游戏规则、随机数或存档格式。
- 目标 `dev`，临时分支 `codex/scalable-world-rendering`；不发布正式服务。
- 所有网格统一投影与受影；使用当前 Three.js 支持的 PCF 阴影。
- 地面高度共享，薄板最小厚度；不以关闭物体阴影掩盖问题。
- 保持 4173 demo 和 4174 主程序可用。

## Review Focus

1. 凹角、近邻平行道路、首尾接缝：地产与连接建筑不得侵占道路或互相穿插。
2. 极宽/高视口、HUD 遮挡和地图边缘：相机裁切与地表必须覆盖真实可见范围。
3. 大地图全景及移动远端：不得固定距离雾化/裁切，局部仍能清晰看到角色。
4. 减少动态/暂停：导航需要刷新，但闲置和模态仍停止不必要绘制。
5. 拖动/触控/缩放与点地：导航不得误触交易；小地图与键盘可访问。

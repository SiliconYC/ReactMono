# 3D demo 地产与演出验收（2026-10-18）

来源：[P006](proposals/P006-3d-art-renewal.md)、[#86](https://github.com/SiliconYC/ReactMono/issues/86) 和所有者对本地 `127.0.0.1:4173` demo 的定向升级要求。实施分支 `codex/3d-vertical-slice`，集成与 PR base 均为 `dev`。

## 玩家可用的变化

- 买地只获得有业主颜色的空地；回合末在“我的地产”选择地块，分别建房和升级。继续使用核心 level 0/1/2、升级费用与租金，不创造第二份经济规则。最高等级、现金不足状态有明确提示；可在以后回合管理已有地产。
- 地图显式划分银杏、风铃、蜜糖、月桂四个街区。同一业主连续建好的住宅自动形成联排，通过共享墙体/屋顶连接并显示户数；空地、其他业主、非地产和街区边界断开。允许不同住宅等级，连接部分使用较低楼层。联排此轮仅改变建筑表现，不增加额外租金倍率。
- 行走过程中保留出发时的资产表现；抵达后播放金币弧线、租金收据及双方独立金额浮字。以 `rent_paid.amount` 的实付数为准，包含破产时不足额支付；演出期间不接受下一步交易。
- 骰子作为当前角色的子节点，在角色头顶滚动和显示点数；结束回合清除旧骰子。跟随镜头读取角色实际动画坐标，投骰时不跳到规则终点；全景可切换，手机缩放随可视区尺寸适配。
- 减少动态效果可在运行中切换，当前移动直接同步终态，骰子和金币尊重设置。短屏和手机横屏的操作栏位于实际视口内，地产面板必要时内部滚动。
- demo 终局显示胜者并可重开；正式 PWA 入口、存档结构、旧地图规则不变。

## 验证命令与证据

- `npm test`：完整 Node 测试，包括旧经济/随机数/存档迁移/批量模拟；新增地产三步、联排边界、真实租金与破产事件测试。
- `python3 tests/browser_demo3d_e2e.py`：生产构建的真实 Chrome；桌面 1280×800、手机 390×844 的地产三步与租金、减少动态效果下的完整 12 轮对局与联排/重开、中途切换减少动态效果、844×390 和 375×600 短屏触控操作。
- 浏览器未使用伪造游戏状态，联排来自固定种子 `20261017` 的真实购买/建设；第一步落在河畔公园：购地 ¥136、建房 ¥68、升级 ¥109，现金依次 1064、996、887。租金案例来自第 7 个玩家回合：桃桃向阿团支付星光露台租金 ¥51。
- 桌面/手机截图、联排、租金和短屏截图生成于 `artifacts/demo-*.png`，CI 新增运行同一浏览器验收并留存这些产物。仓库内关键证据见 `docs/art-renewal/evidence/demo86/`。

## 独立审查及失败记录

独立只读审查未发现 P1；要求修复三项 P2：金额浮字没有卡片定位上下文而重叠、媒体偏好只读一次、固定最小高度裁切手机横屏操作栏。新增真实浏览器检查先复现，再分别修改：卡片相对定位；订阅媒体变化；按实际 `dvh` 布局并使面板可滚动。未删除原有测试或放宽核心验收。

本轮另保留开发期测试失败：初始缺少地产状态/联排实现，浏览器找不到地产管理；新测试把升级费误写成 ¥102，经核对既有核心费率 80% 修正为 ¥109，没有改变游戏规则。截图检查还修正了手机地产卡与位置卡的轻微相交。

## 边界与回滚

这仍是本地 16 格双人 3D 切片，不是正式入口的 3D 替换；不代表 #73/P4 正式版验收完成。尚未覆盖真实手机 GPU、长时发热、多地图 3D、完整 AI/PWA 的 3D 适配。回滚通过撤销本轮提交/集成 PR，旧正式游戏不依赖 demo 模块。不得把新增 CI 配置当作尚未运行的远程 CI 已通过。

## 本地最终结论

2026-10-18：Node **130/130**、真实 Chrome **7/7** 通过（浏览器 65.075 秒）。独立审查者在修复后再次以只读 Chromium 检查动态减少动画、两种短屏触控及桌面/手机金额定位，确认三个 P2 均关闭，无剩余 P1/P2；CI 新增路径与构建顺序复核通过。远程 CI、PR 与最终合并状态可从 #86 的关联 PR 查证；本地通过不代替尚未完成的远程流程。

## 远程首轮失败与验收时序修正

[首轮 CI](https://github.com/SiliconYC/ReactMono/actions/runs/39053823565) 的 Node 与 2,000 局经济模拟通过，3D 浏览器 7 项中 5 项失败（510 秒）。原始日志见 `evidence/demo86/ci-first-attempt.log`：中间地名与格号跨 RPC 读到了不同帧；租金的多次读取跨过 1.9 秒演出窗口；失败页面未清理，后续 WebGL 场景积累。此轮未作为合并通过证据。

测试改为在真实操作前安装浏览器观察器，一次记录格号/地名、抵达前资产、可见租金、双方金额与几何位置及操作锁，然后读取不可变轨迹；保留可见性和全部金额/边界判据。减少动态效果从真实媒体 change / 点击事件到正确终态在浏览器内实测，仍要求低于 700ms，避免将驱动通信延迟算成产品响应时间。失败 context 也由 cleanup 关闭；新增六分钟步骤上限和逐项日志，不绕过失败。

修订后本地 7/7 再次通过（59.537 秒），媒体切换响应 14.1ms、后续减少动画投骰 11.7ms；独立审查确认保留了原验收强度。未修改产品规则/演出代码来迎合测试。最终远程结果以 PR #87 最新 head 的检查为准。

# P4 #71 — 经济与策略交叉实验（预先登记）

本 Issue 不是推新玩法。严格遵守 #45 的 `450000 + 97*i` 1000 个固定种子、地图、人数、初始资金及三策略轮换配置，以现行规则作为 A。B 仅将 **最大轮数调为原值的 75%（向下取整）**，作为缩短长局的最小可逆配置候选；**不修改线上默认值，不改变既有存档或策略源码**。

预注册采纳门槛（实验前定义）：
- 所有样本均合法、终局且同种子同设置下策略决策可复现；B 必须保持 A 动作序列的前缀（忽略最终 `phase` 差别），才属于真正可比对照。
- B 的平均动作/模型等待下降至少 20% 且胜者变化率不超过 10%、破产人次相对下降不超过 20%、三风格至少各 200 席。不满足任何一条即不建议替换默认局长。
- 即便达到机器阈值，缺少真人实验时也只能建议开放为用户可选参数，**不能宣称主观趣味提升**；需有玩家长局等待与策略反馈才考虑改默认。

完整交叉维度：每组 1000 局、两张地图各约 500、2～4 人、保守/平衡/进取、地产/升级、银行、股票、贷款、卡片、设施、破产/清算，保留每局种子、行动轨迹、获胜者、资产集中及引擎动作分布。输出原始文件 `artifacts/issue71/p4-balance-paired-1000x2.json`（即 CI artifact，不能用本文件假称已经运行）。

速度口径：#70 的电脑界面延迟是展示等待，和 CPU 选行动时间不同。实验在相同引擎轨迹中记录每局动作数与按 #70 纯调度函数计算的名义等待，**不是**真实用户计时。#70 的 Chromium 真实墙钟数据独立交叉核对，不能将两种计时相加或当作因果结论。

任何旧档仍采用内部 `maxRounds`；不做静默迁移。超过 100 局的原先测试全部保留，离线/PWA/旧存档的 CI 回归完整执行。无真人试玩样本应明示缺失。


## 真实首轮执行结果（PR #84）

- [实验 CI #39011761021](https://github.com/SiliconYC/ReactMono/actions/runs/39011761021) 已完整执行配对 1000×2；[原始 artifact #12093525246](https://github.com/SiliconYC/ReactMono/actions/runs/39011761021/artifacts/12093525246)，JSON 约 24.6 MB（压缩约 1.45 MB），含全部种子、逐局两组每一步命令、玩家资产、事件分布与未遗漏失败记录。重复以 `node scripts/p4-balance-experiment.mjs` 执行。
- A（现有配置）1000 局、241239 次动作、零非法行动；两图各 500，2/3/4 人 334/334/332。轮数上限 **97.2%**，平均每局 **32.572** 轮、**96.088** 玩家回合、**241.239** 次动作；162 人次破产。平均净资产最大玩家占比 **51.47%**，头两名差 **608.95** 游戏币。三策略席次/获胜：保守 1002/251，平衡 1000/342，进取 996/403。
- B（仅将轮数上限乘 0.75 向下取整）1000 局、187525 次动作、零非法行动；轮数上限 **99.4%**，平均 **24.597** 轮、**73.293** 玩家回合、**187.525** 次动作；65 人次破产，最大净资产玩家占比 **47.44%**，前二名差 **435.16** 游戏币。
- **配对前缀分歧 0/1000**，证实到候选游戏提前结束前没有更改电脑策略、随机轨迹或账目；然而 **159/1000（15.9%）局胜者改变**（预设阈值 ≤10%），破产人次从 **162 减至 65（−59.9%）**（允许损失 ≤20%）。行动数减少 **22.27%**，#70 名义展示预算减少 **22.43%**，收益虽过 20% 门槛，但双重负面门槛失败。
- 金融与互动样本完整：A/B 股票事件 2918/2674，银行 54559/42525，贷款 7107/4206，卡片 18604/14737，特殊设施 28412/21843。样本显示局长缩短尤其削弱贷款/违约与破产积累阶段，不等于机器“更有趣”。
- **最终裁决：拒绝调整默认局长与 AI 策略权重，维持线上原配置。** `decision.machineGate=REJECT` 与 `decision.defaultChange=REJECT` 已在原始 JSON 标记；未触碰规则源码、持久化、旧存档。用户已可自行选择最大轮数，因此不需要额外 UI 或迁移。
- **限制**：所谓等待预算仅按 #70 的定时器模型由动作数估算，不是实际浏览器墙钟；#70 的真实 Chromium 2～4 人三组等种子试验另有 CI artifact。现有无真人参与（`humanFeedback=false`），不能声称玩家认为原局长或新局长更有趣。若以后有真人对照反馈，可重新提出新实验方案。

# P3-02：2～4 人规则核心及旧存档兼容

实施范围：Issue #31；旧两人单人电脑入口保留，UI 配置和本机真人轮流交互归 #32。

- 配置支持 2～4 名玩家，各有唯一 ID、姓名和 human/computer 类型；不填写类型时与 P2 一致（首位真人，其余电脑）。
- 玩家破产只淘汰该玩家，手持现金上限支付租金，破产者地产临时归为无主；#35 实现完整清算与售地。剩余两人以上继续，轮到任何人都跳过已淘汰者。

- 存档规则状态升级至 v3；原 v1 经既有地产字段迁移，v2 在校验原完整字段及校验和后升级 v3。旧两人档的人名、类型、位置、产权、卡牌和随机数进度不变；不认识未来版本时拒绝而非损坏数据。
- 验证：300 组（每个人数 100 组）无界面确定性整局重复；2→3 人破产不中断、回合索引不指向已淘汰者；100 组 P2 基线行为（允许 schemaVersion 从 2 升到 3）；Chromium 加载 JS 模块执行 3/4 人完整对局。#32 负责浏览器可配置多人开局与真实 UI 轮换。
